# c04 实测独立助手复核

复核身份：**助手复核，非用户确认**。本文件仅用于实验完成后的方法评测，不进入提取或核对模型输入。初始图独立判断已经先于模型结果固定在 `c04-c05-baseline.md`；以下在该判断基础上检查实际核对记录，不使用外置 oracle。

## 第 0 轮：正确命中返回结果身份错误

审查文件：`cases/c04/rounds/r000/audit.json`。该文件原始 SHA-256 为 `65ad3fba6f601bde74341f471935a185589c1b86cf98437ebf41cdeeb3f1a2a5`。

实际模型记录有 1 个背景项、10 个业务项：9 个业务项为 `represented`，1 个为 `mistranslated`，没有 `unknown`。程序据此选择 `revise`，唯一明确差异为 `finding_8`。

`finding_8` 的主要结论正确：源文第 13 行要求返回成功那次调用的 body；重试输出的实际 body 是 `result_008`，但重试成功出口 `block_010` 的 `ir_020` 返回 `result_004`，其定义来自首次 fast 调用。模型同时指出该实际引用与图级成功返回约束冲突，但只列出一个错转发现，没有将同一根因重复计为两个缺陷。

该发现的证据链涵盖：

- 源文 `SKILL.md:13` 的完整对应句。
- 当前返回输入事实 `fact:/blocks/9/instructions/1/inputs/0`。
- 当前实际定义引用 `fact:/blocks/9/instructions/1/inputs/0:link`，其 `result_004` 指向首次调用输出。
- 重试 body 定义 `fact:/blocks/7/instructions/0/outputs/0`，其 ID 为 `result_008`。
- 全局成功返回约束 `fact:/constraints/2`。

因此这次命中依靠的是实际定义—使用身份，不只是块名或草稿名称。`finding_7` 另外将首次 fast 成功和 archive 成功路径判为保留，明确将重试成功问题留给 `finding_8`，没有让宽泛的成功要求保留结论掩盖该路径错误。

## 建议定位正确，关于 link 的操作文字需要解释

模型建议引用的三个已有事实，程序映射为两个实际图位置：

| 模型目标事实 | 程序解析的实际 CFG 位置 | 复核 |
|---|---|---|
| `fact:/blocks/9/name` | `/blocks/block_010/block_name` | 当前块名确实描述返回首次 body；改为重试 body 的标签有助于消除冲突，但不是主要修复。 |
| `fact:/blocks/9/instructions/1/inputs/0` | `/blocks/block_010/instructions/1/inputs/0` | 主要修复位置正确，当前实际值为 `result_004`。 |
| `fact:/blocks/9/instructions/1/inputs/0:link` | `/blocks/block_010/instructions/1/inputs/0` | 派生绑定事实正确映射回对应输入，没有虚构 CFG 中的 `link` 字段。 |

模型建议中的“把对应 link 的定义位置改为 /blocks/7/instructions/0/outputs/0”在概念上指向正确的重试定义，但**不能执行为手工修改受控文档中的 link**。link 是由实际标识推导的证据；应在完整重提取候选中让返回值引用重试的结果，由编译器和受控转换程序重新生成 ID、位置和定义链接。当前程序返回的目标位置仍是实际 CFG 输入，因此没有把这段措辞转换成对派生文档的直接修改。

## 误报与保留项检查

本轮没有发现额外的明确语义误报。其他业务项对来源、密钥条件、重试触发和次数、回退入口、archive 唯一业务参数、archive 失败返回、密钥禁传声明及四条终态返回前的状态追加，与初始图记录一致。

需要保持判定边界：

- `represented` 在这里表示源文要求与图记录的对应，不证明工具执行、文件写入或实际密钥安全。
- 模型没有把 archive 的资源定位符误当成额外业务参数。
- 模型没有因为 `success` / `failure` 是具体状态字符串而要求改写源文未规定的格式。
- 10 个辅助 `dispatch` 操作被纳入保留项的证据覆盖；本轮未单列其执行语义为未决。此项与其他独立核对轮次的粒度可能不同，不能由“没有 unknown”推出已证明开放操作的执行行为。

## 最终方法结论

**初轮核对真实命中，定向反馈定位正确；后续提取执行失败，修复未完成。** 最后有效图仍是包含该缺陷的初始图。运行没有生成核对器假通过结果，也没有把旧的结构有效图冒充成功图。

该案例提供了缺陷识别和反馈定位的正面实例，同时保留了真实传输失败的工程结果；它不提供本次反馈已经完成返回身份修复的证据。
