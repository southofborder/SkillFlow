# 013 字段关系降精度候选：助手复核

**确认命中受控缺陷。**审查执行成功，唯一发现为 `f_ir009_body_identity_lost`。目标 ann_0248 精确对应首次响应处理中的 atomic_ops/1，但结论不只依赖位置重合。

候选将成功响应已有的 body 值改为 compute，只有 possible 依赖。源文要求 body unchanged，EM11 也区分字段原值保持与计算依赖；因此该改动确实丢失了字段组成和原值身份。审查器指出了这条实质差异及其对首次成功返回路径的影响。

恢复 select_part(input[0], ["body"])、沿用 fast_fetch_first_body 输出名及现有 output_bindings，是当前规格可表达的定向建议。它不需要修改 CFG、处理模式、观察或重试身份。本轮仅记录建议，没有执行修复。

原发现的辅助比较句稍显过满：ir_017 的 opcode 不完全相同，其 error 字段也不是成功 body 的关系。核心判断仍由源文与 EM11 独立支持，应将比较收窄为“三条成功路径都应保留各自响应的 body 原值”，不因此把整项算作误报。

本例没有额外独立发现；评测身份是助手复核，不冒充用户已确认或自动语义证明。
