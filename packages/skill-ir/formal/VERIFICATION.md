## 证明与差分边界

审计的五个定理为 `check_iff_wf`、`check_sound`、`check_complete`、`wf_rename_iff` 和 `check_rename`。前三个证明声明式有限结构谓词与 `decide` 参考检查器的反射等价；后两个证明三个结构 ID 命名空间分别一致单射改名后，`WF` 与检查结果不变。未使用占位证明、自定义公理或跳过内核检查的方法。

差分覆盖 57 个规则 fixtures、30 个原始图、1,060 个小图拓扑案例、160 个固定种子案例、80 个改名案例、80 个块与边存储次序案例及 284 个单项 mutation。改名案例额外包含上下文名称的一致改名，这一额外性质只有测试证据，不属于本次结构 ID 的机器证明。

固定原始输入清单为 [fixtures/review30.json](fixtures/review30.json)，使用仓库相对路径，不含 CFG 副本或人工标注。015/F03 固定第 3 轮，其余固定第 1 轮。每张图从原始 `analysis.json["cfg"]` 读取；结构接受不代表原图已成为语义标准答案。

有限差分不等同于 Python、JSON 解析与桥接获得了端到端机器证明。结构定理不证明源文覆盖、条件可满足、全路径值可用、循环终止、操作执行正确或无敏感信息泄露。这些界限在规范和复现说明中保持一致。
