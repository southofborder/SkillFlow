# 本地调用记录稳定性修复（2026-09-18）

此次修复针对 v4 七例运行中保存 `transport.json` 时发生的 Windows 文件替换失败。改动限于记录、传输检查点和错误传播，不改核对协议、原图 IR、提取 Prompt 或语义判断。没有远程模型调用，没有恢复暂停批次，也没有修改历史结果。

## 保存与重试

`ArtifactWriter` 仍先脱敏，再调用共用的 `atomic_write_text`。以独占创建方式写入唯一临时文件，完整写入并关闭后，才替换正式文件。新写入使用精确 UTF-8 字节，不再隐式转换 Windows 换行。

只有替换阶段的 Windows 错误码 5、32、33 进入本地重试：最多尝试 7 次，等待为 0.05、0.1、0.2、0.4、0.8、1 秒，合计 2.55 秒。重试始终使用同一份已写好、已关闭的临时文件；不重新序列化，不发起 HTTP 请求，不改变模型调用计数。目录创建、临时写入及其他替换错误不进入该重试。

重试耗尽时保留完整临时快照，错误记录包含目标、阶段、临时位置、SHA-256、替换次数与原始 OS 错误码；正式旧文件不被截断。半写文件没有完整快照标记或摘要，清理失败也不覆盖最初写入错误。中断仍按中断传播。

暂存文件不是已接受的模型答案，不自动扫描或提升为正式记录。完整调用恢复仍依赖原有的提示词身份、摘要、完整 transport 和响应一致性检查。只有响应前缀时不能恢复尚未收到的内容。这里保证的是正常进程中的写入、关闭与替换流程，不额外宣称突然断电后的磁盘持久性。

## 错误传播与调用保护

新增 `ArtifactWriteError`，明确表示本地保存失败，不继承网络异常。自定义记录回调抛出的 `OSError` 也在回调边界转换为本地错误，不再被 SSE 包装为 `network failure`。

各层最终保存遵循相同规则：

- 没有先前错误：保存失败必须使本次执行失败，不能返回成功。
- 已有本次错误：保留原始异常，附加保存错误和 `recording_failed`，不能用第二次保存错误盖掉第一处失败。
- 本地失败或附加保存失败均阻止 HTTP 重试和外层核对执行重试。
- 显式记录本次异常，不从调用方正在处理的旧异常推断本次失败。

如果完整、可校验的 transport 已保存，而最终 `call.json` 保存失败，在线执行仍报告失败；既有 `SavedResponseClient` 可以从完整 transport 离线恢复，不重新请求模型、不改写原始调用文件。格式错误、证据错误及不完整响应不会因此变成成功。

## 流式检查点

普通检查点改为距上次保存完成至少 5 秒后再保存，避免一次慢写耗尽整个间隔、下一数据块立即再写一遍累计记录。开始、结束和异常时仍强制保存；收到最后一个 `[DONE]` 块后不额外执行普通检查点。

HTTP 状态、已收字节、内容、`finish_reason` 和 `[DONE]` 仍按实际观察保存。完整流最终保存失败不抹掉已经观察到的完成事实，但也不将本地持久化失败当作执行成功。

这减少了重复全量序列化和替换的频率，未引入异步写线程、追加日志或新恢复架构。普通检查点间隔变长意味着突然终止进程时可能丢失的中间记录窗口更长；现有开始、正常结束与可捕获异常的强制记录继续保留。没有据离线测试宣称模型生成或整轮实测加速了某个比例。

## 验证与历史边界

专门测试覆盖真实 Windows 文件句柄阻止替换后释放、同一快照本地重试、持续失败保留旧文件和完整暂存、半写与清理错误、脱敏、网络首错与保存次错、完整响应后保存失败、调用方正在处理旧异常的情形，以及双层不重发保护。流式慢写测试验证保存自身耗时超过间隔时不会连续写盘。

验证结果：全套回归 **1302 项通过**；之后补齐重试决定保存失败的首错保护，并对相关记录、SSE、网络重试与反馈运行测试复验，**135 项通过**。后者包含前者已运行的测试，不将两者直接相加作为不同测试数量。真实 Windows 文件占用用例在本机运行通过，没有跳过。

核验 **3784 个既有文件**，冻结输入、生产提取 Prompt、IR、结构规则、形式化源码以及历史产物均无变化。详见[验证记录](../../tmp/local-recording-fix-20260918/validation.json)、[全套回归日志](../../tmp/local-recording-fix-20260918/pytest.log)和[最终针对性回归日志](../../tmp/local-recording-fix-20260918/guard-pytest.log)。测试全部使用本地模拟或本地文件，没有真实 API 调用。

历史 v4 的 c01、c03 仍是本地记录失败，c05 仍是证据编号错误。历史报告不追溯改写。源码身份已改变，新的在线运行必须使用新目录；严格来源绑定继续阻止当前代码冒充旧实现续跑或重放旧目录。旧运行的原始记录及当时生成的离线重放产物保留。
