状态：实现与离线验收完成。按当前用例身份去重，3,893 项通过、0 项未解决失败、1 项因 Windows 符号链接权限跳过。没有启动新的真实 GA4 分析。

本轮范围是 2026-10-29 批准的实现和离线验证，没有启动真实分析目标请求、模型探针、Skill 执行或旧运行续跑。正常流程仍为七个语义请求、两个 worker；annotation 由程序组装，Task、任务对应和 sensitivity 的输入隔离保持。

## 实现变化

- 显式 CFG 中的 `merge`、`member`、有类型的 `branch` 和 `append` 进入实际编译、传播和保存格式。循环与成员身份由程序生成；模型不填循环管理表或迭代编号。
- 循环内部维护有限关系事实，退出求解后封存。普通 Data 身份没有改成可任意覆盖的可变节点。入边元组、外层成员、内层成员和接收方保持对应；对于已表示的成员 occurrence，无参数和同参数调用也有配对的响应身份。未知次数的重试／分页仍是有限调用族，不是每次具体执行各建一个身份。
- 空集合不执行成员体；已知布尔和集合条件使用实际值，未知条件保留可能路径。局部不支持有明确截止，工程异常不被一律改成未决。
- 嵌套 `each`、成员字段、基数、敏感来源和边界对照贯通。整体读取不自动成为整体必要，真实完整 metadata 要求继续保留。
- 合法的空候选可直接 yield 既有值；段数组默认 fixed，非固定才提交 partial。按实际 kind 校验，普通证据与适用源文证据分别继承，替换槽与可修正的目标引用分离，CFG literal 等操作数有明确变体。
- 格式由实际类型生成，规则保存在校验器附近，少量示例通过真实验证和编译。生成自查留在原调用中，不输出检查表或增加请求。
- 新协议的成功和失败均可离线重放。DOE 原计算失败时重放原错误，不把“缺少成功 manifest”当作新错误，也不伪造 DOE 结果。

## 仍保留的精度边界

1. 显式累计是有限的初始值／追加贡献方程，保留成员与接收方关系；不是逐轮计算出的具体数组。即使输入是已知两项，通用 CFG 累计也不因此证明最终数组恰好两项、顺序完全确定或排除了全部抽象前缀。既有结构化 for_each 的映射集合仍保留源顺序和基数；两种表示的精度不能混为一谈。
2. 未知外部内容、路径可行性、别名与缓存命中次数没有通过静态求解自动变成已知事实。调用边界、真实版本和可能的过去交付可以保留，精确计数限制仍需单独说明。
   逐元素 constraint 的显式作用域目前仍引用已有结构化 for_each event；程序生成的显式 CFG 循环作用域不是可由模型填写的 constraint-scope 引用。嵌套 each 的内容需求与敏感范围不受这个限制，未表达的作用域限制不能被补写为满足。
3. 资源预算耗尽不是成功收敛；未支持的域或缺少真实成员记录不能被空结果代替。普通工程错误仍是工程失败。
   默认 100,000 的现有候选预算分别约束候选组合、关系事实、条件路由和入边状态；全局 `resource_limit` 可停止尚未处理的独立分支，不能将它描述为局部缺口隔离。有限表示不意味着支持任意规模 Skill 的实际资源消耗。
   多代迭代中的不同携带值若共同依赖超出有限摘要的历史选择，这份联合使用会局部保持未决；不以 x_A/y_B 的自由组合冒充已知配对。单个游标与常量、当前接收方，以及同一个值的重复引用不触发这项截止。普通共享 handle 复用与创建来源分离处理。
4. 离线通过不证明源文建模完整、敏感性穷尽、自然语言需求最小或方法优于直接 GPT。没有新真实运行的 tokens、总耗时或准确性收益可报告。
