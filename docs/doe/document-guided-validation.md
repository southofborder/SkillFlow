## 1. 已实现的最小范围

- 四份简短英文 Markdown 工作文档：流程、实际数据处理、任务对应、敏感性。没有新的业务 Schema、分组接口或 A/B/C 在线编排。
- 英文短模板只提供本步职责、已有成果、全局义务与未决问题、相关原文、输出要求。流程理解必须收到完整可读源文；Task 来源仍独立，任务对应拒绝敏感性文档。
- 原文按冻结文件和物理行范围提取，合并重叠范围，保留换行和原语言。脚本复制要求明确的现有操作与源文范围，程序不按名字猜依赖。
- 批次类型从现有 CFG／标注类型投影。模型明确提交块、控制边和原子关系；程序只组合内容，调用现有完整编译器，不补边或补需求。
- 辅助审计复用现有调用记录、锁和原子保存；保存响应后恢复不重发。批次替换保留旧版，明确依赖发生变化时拒绝继续使用旧附件。

这些是可执行的离线辅助函数，不是已经完成的生产模型调度器。补充原文请求循环、按语义影响自动决定重做步骤、整条文档引导在线链尚未接入。本轮不声称这些能力已经完成。
