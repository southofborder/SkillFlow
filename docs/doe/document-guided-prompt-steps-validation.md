# Prompt 分步收紧：接通与离线验证

本页保留前一阶段流程及其验证记录。当前八调用、扁平标注和集合扩展见[现行设计](document-guided-analysis.md)及[新离线验收](document-guided-eight-call-validation.md)；下述七份 Prompt 和串行流程属于此前版本。

日期：2026-10-27。目录：`D:/projects/SkillFlow`。

本轮已把活动路线改为**独立请求继承短文档，最后提交完整 CFG 和完整标注**。没有调用模型，没有恢复 GA4 旧运行，没有启动三例或长 Skill 实验，也没有提交或推送 Git。

入口：[当前设计](document-guided-analysis.md) · [中文样张与七份实际 Prompt](../../examples/document-guided/index.html)。

## 已接通的流程

```text
独立 Task
    → 流程理解 → 同一流程的关系补全 → 一份完整 CFG
    → 全局源文核对
    → 实际处理文档 → 任务对应文档 → 敏感性文档
    → 一份完整标注 → 独立语义审查
    → 现有传播、反向需求、限制、敏感范围与 DOE
```

新入口只有 `prepare / run / replay`；不再让调用者安排 `step / graph-compose / compose`，也不接收批次计划。模型负责完整对象中的业务关系；程序负责保存、精确原文复制、既有编译和引用校验。

正常流程是 10 个语义请求，结构纠正另外计数。最多一次语义修复，预算在本入口内明确记录：图表示修复消耗该预算；若预算仍可用，标注初审可选择固定 Task 修复或隔离修订 Task。没有逐工作文档的独立审查。

Task 只读源文与用户请求；任务对应不读敏感性文档。初审意见只进入经校验的完整标注修复，不灌入中间任务对应文档。Task 单独修订时，实际处理与敏感性输入未变，因此复用这两份文档，只重做任务对应、完整标注及独立复审。

## 本轮处理的实际问题

| 问题 | 本轮处理 |
|---|---|
| 拆 Prompt 被做成了业务图和标注片段拼接 | 活动入口改为固定理解步骤和完整对象提交；原批次 helper 仅留给既有离线夹具 |
| 图核对重复发送完整受控文本、事实映射和代码 | 模型读取紧凑图事实；完整受控文本、图位置映射、Lean 校验证书保留在审计中 |
| 逐行和逐底层 fact 登记占用大量输出 | 删除图核对正常响应的强制逐项登记；实际引用仍严格验证，语义遗漏仍需审查 |
| 保留源文歧义却因无法替源文选答案而整链停下 | Prompt 检查歧义是否被忠实保留；合法无法判断单独记录，可继续诊断计算 |
| 已接受请求恢复时被误判不同 | 修复保存 Prompt 读取的 CRLF 规范化问题，按原字节比较 |
| 未修改的工作文档重复生成 | Task 修订复用处理与敏感性文档，不重发无关步骤 |
| 收据未观察到 HTTP 尝试却容易显示成 0 | 未观察项保留未知；原生 CLI 派发、usage 和请求耗时单独按收据统计 |

不存在合法对象时仍停止依赖步骤；传输、身份和实现错误不进入结构纠正。诊断性计算不把未完成核对改为通过，不解除已有需求或限制阻断，也不证明字段可删。

## 完整输入规模

GA4 使用既有冻结源文与保存图，仅进行只读重新渲染，没有产生新的模型接受响应。

| 对照对象 | 字符 | UTF-8 字节 |
|---|---:|---:|
| 旧核对逻辑 Prompt | 1,172,331 | 1,290,243 |
| 新核对渲染 Prompt | 552,837 | 553,060 |

全部 1,663 项图事实和完整源文仍保留。60 处与源文完整行精确相等的代码副本改为原文范围引用。旧运行实际派发前曾另行重编码为约 992,720 字符；表中第一行是旧逻辑 Prompt，不混同该传输显示。

新输入仍约 55 万字符，不能据此称为已经很小。这里没有测 tokenizer，也没有新模型 usage；**不宣称实际 token、费用、首次合法率或总耗时已经改善**。后续判断应看真实完整链的结果。

合成样张另外给出七份最终发送形态的 Prompt、完整 CFG 与标注。它们独立于 GA4；没有用保存的 GA4 产物拼出新版“成功结果”。

## 离线验证

只验证与本次收紧直接相关的三组职责，不执行整仓全量 pytest。

| 组别 | 实际检查 | 结果 |
|---|---|---|
| 输入及填写 | 步骤职责、Task/敏感性隔离、精确范围与回退、完整格式、实际样张、传输准备 | 最终文档/恢复/样张/传输定向组 19 passed（6.25 秒）；随后增加的传输硬限制与成本未知项检查连同恢复共 6 passed |
| 完整对象及后端 | 完整图纠正、原文代码复制、单响应标注、公共加载、传播、DOE、重放与篡改拒绝 | 3 passed（25.33 秒） |
| 固定流程与停止政策 | 正常全链、图核对 cannot_assess 后诊断继续、普通重开不重发、零客户端重放 | 2 passed（115.53 秒） |
| 一次语义修复 | 固定 Task 修复、独立复审、审查意见不泄漏到任务对应 | 1 passed（33.19 秒） |
| Task 修订复用 | source-only Task 修订、新 Task 身份、复用处理/敏感性、只重做相关后继 | 1 passed（31.73 秒） |
| 图核对展示与引用 | 真实图事实、完整受控文本/证书不变、严格引用、取消机械覆盖表、保存响应重放 | 定向组 132 passed（58.01 秒） |

各组有重叠，不相加为整仓测试数。完整正常链与诊断链使用真实编译器、现有 Lean 可执行文件、标注校验、传播和 DOE，只有模型响应由合成客户端注入；不是一次真实线上实验。两条链各有 10 次注入完成、0 次结构纠正。修复路由分别有 15 和 14 次注入完成，在后端入口暂停，避免重复已经验证的计算。

恢复用例验证：接受 flow 后暂停，继续时不重发 Task 或 flow；接受 relationships 后再次暂停，离线重放恢复同一停止位置。Windows CRLF、中文原文的内容保持，没有用换行改写来绕过身份检查。

## 使用方式与当前边界

在仓库根目录运行：

```text
python -m tools.doe.document_guided_pilot prepare --input <Skill> --run-dir <新目录>
python -m tools.doe.document_guided_pilot run --run-dir <准备目录> --profile <已验证的CLI配置>
python -m tools.doe.document_guided_pilot replay --run-dir <运行目录>
```

实际调用保留 `gpt-6.1-sol / max`、独立新会话与现有收据验证。新入口不会自动探测连接，不将旧停止运行换个身份继续。实际派发前检查完整传输包的硬长度上限，超限停止，不能自动删源文后再次发送。

本轮已形成可自动执行的固定路线，并在注入响应下完成后端连接。**尚未验证真实模型在这个新路线下的完整遵循率、语义质量和成本。**本轮到此结束；没有自动恢复 GA4 或扩展到 30 个长 Skill。
