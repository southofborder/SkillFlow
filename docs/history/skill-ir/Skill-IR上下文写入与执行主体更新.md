# Skill-IR 上下文写入与执行主体更新

> v3 阶段历史实施说明：本文保留当时的字段更名、效果补全与验收范围。下文的版本号及未决字段属于该阶段，不是现行入口；当前协议以[安全语义标注规范](Skill-IR安全语义标注规范.md)和[表示契约与一次标注修复](SkillFlow-表示契约与一次标注修复.md)为准。

本次更新将独立安全标注升级为 v3：执行主体字段统一为 `operator`，补充 `context_write`，明确空效果与数据绑定变化的区别。规范以 [独立安全语义标注](Skill-IR安全语义标注规范.md) 为准。原 IR、生产提取提示词、结构规则、受控回述及事实保持证明、Data 契约和历史实验保持不变。

## 四字段与效果边界

profile 仍只有 `operator`、`roles`、`effects`、`evidences` 四个字段。`operator` 使用无重复多值列表，固定值为 `llm`、`agent_runtime`、`tool`、`human`，表示参与当前动作执行的主体；具体工具名仍保留在 IR 和证据中。`actor` 不再接受，也不保留兼容别名。证据及未决项中的字段定位同步使用 `operator`。

`effects` 保持有序且允许重复；每个非空效果出现都有对应 `effect_index` 的证据。新增 `context_write` 表示创建、更新或删除共享运行时、会话或环境条目。普通 IR 结果定义、局部临时结果、单纯返回不自动成为共享上下文写入；文件写入与模型实际观察仍分别使用 `fs_write` 和 `model_observe`。

删除共享上下文绑定可以不读取旧值。例如删除 `session.cache` 的绑定，只能据此记录上下文写入边界；不能自动补出 `context_read`、`transform` 或 `model_observe`。如果原文另有读取、变换或观察动作，仍应根据其依据分别标注。

空 `effects` 说明当前词表没有适用的效果步骤，不表示 IR 是 nop，也不规定 IN 等于 OUT。原样引用可复用 Data ID 并建立新的结果位置绑定，而无需变换内容。不能因为 opcode 是 `dispatch` 或 `return` 就忽略实际存在的读取、传输或观察；无法确定是否有适用效果时，使用 `unresolved`，不能伪装成已确认空效果。

标注指令正文及固定执行规则继续使用英文，解释理由使用中文；源文、代码和证据引文不翻译。`wide-read-agent-v3` 保留原宽读取和工具结果回传假设，并通过规则 EM07 明确共享上下文变更、结果定义及删除不隐含读取的边界。没有新增模型角色或传播期间的解释调用。

## 版本、记录与展示

当前标注契约为 `security-profile-v3`，独立运行身份为 `skill-ir-security-profile-v3`，运行 `schema_version` 为 3。当前批次、报告、导出和审查模板绑定新契约；旧版字段和旧版记录明确拒绝，不迁移历史响应，不将历史结果重新解释为 v3。

传播记录外壳继续使用 `skillflow-propagation-record-v1`，只将 `profile_schema_version` 绑定更新为 v3。事件与有序效果仍一一对应。`context_write` 的接收边界是运行时上下文位置；删除绑定时允许事件没有数据输入或输出，但必须保留边界。记录容器不会根据 effect 自行改变状态，也不从自然语言理由生成传播规则。

报告使用执行主体 `operator` 并按顺序显示九类效果的步骤和证据。效果覆盖统计仍按具有该效果的 IR 数计数，同一 IR 的重复效果不增加覆盖数量。effects 顺序未决仍显式显示，不能把格式校验或全量覆盖解释为顺序已确定。

本次未增加数据流摘要、`transfer_specs`、CFG 遍历、固定点求解或新的传播 API。现有 30 例未重新标注；冻结输入、旧实验、ZIP、PNG、评审及已交付审查页面不重写。之前的 [操作粒度与有序效果更新](Skill-IR操作粒度与有序效果更新.md) 保留 v2 历史正文和当时测试结果。

## 离线验收

验收覆盖四字段与固定主体词表、旧字段拒绝、`context_write` 逐次证据、空效果和未决的区别、已接受响应恢复、零 API 重放、旧版运行拒绝、报告及审查模板，以及传播记录的绑定与序列保持。

综合记录示例扩充为 18 条 IR，在原有观察、删减、网络、重复效果、中间结果和分支候选场景之外，加入原样引用建立新结果绑定、原样写入共享上下文、删除绑定但不读取内容三个场景。示例中的状态与数据绑定由作者给出，不能据此宣称已实现传播推断。

从仓库根目录执行：

```powershell
python packages/skill-ir/examples/propagation_record_demo.py
python -m pytest packages/skill-ir/tests/security_profile packages/skill-ir/tests/propagation -q
python -m pytest packages/skill-ir/tests -q
```
