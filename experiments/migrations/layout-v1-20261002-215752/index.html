历史读取与旧续跑是两回事

只读加载核验冻结材料、真实接受响应及可重建编译关系，不重写旧生产者身份。继续运行和原运行重放仍检查原实现摘要，迁移后的实现不同，旧运行会拒绝执行。

历史地址只按清单的精确旧相对／绝对地址映射，并核验声明的文件摘要；不根据相似名称、路径后缀或“最新结果”猜测。地址解析不能绕过续跑身份检查。

此次新布局离线验收做了什么

新建独立运行身份，每例注入一份历史真实已接受响应。然后验证解析、编译、保存、接受响应恢复和零 API 重放。新运行没有冒充旧生产者，也没有产生新的 DeepSeek 响应。

注入记录中的 HTTP 参数、模型用量及实际返回模型明确不可观测；原模型记录仍在封存材料中。DOE 输出与原文件相同，运行身份和审计材料分别绑定。

下一阶段 DOE 应另存回溯、敏感性与必要性判断，不回写本轮传播事实。后续实现归 src/skillflow/doe/，本轮没有空模块或假入口。契约可能观察不等于已经发生的数据泄露。
