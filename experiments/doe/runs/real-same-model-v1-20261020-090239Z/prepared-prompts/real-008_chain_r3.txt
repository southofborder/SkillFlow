526:   }
527: }
528: ```
529: 
530: To get the next page:
531: 
532: ```bash
533: curl "https://graph.facebook.com/v25.0/act_$META_AD_ACCOUNT_ID/campaigns?fields=id,name&after={AFTER_CURSOR}" \
534:   -H "Authorization: Bearer $META_ACCESS_TOKEN"
535: ```
536: 
537: **Limits:**
538: - Default: 25 records per page
539: - Maximum: 5000 records per page (use `limit` parameter)
540: 
541: ## Rate Limits
542: 
543: Rate limits are calculated per ad account using the formula:
544: 
545: ```
546: Call Limit = 60 + (400 × Active Ads) - (0.001 × API Errors)
547: ```
548: 
549: - Minimum: 60 calls per hour
550: - Increases with more active ads
551: - Decreases with API errors
552: 
553: **Handling Rate Limits:**
554: - Check `X-Business-Use-Case-Usage` header for current usage
555: - Implement exponential backoff when receiving 429 responses
556: - Start with 1 second delay, double on each retry (max 5 retries)
557: 
558: ## Token Management
559: 
560: ### Extending User Access Tokens
561: 
562: Short-lived user tokens (~2 hours) can be exchanged for long-lived tokens (60-90 days):
563: 
564: ```bash
565: curl "https://graph.facebook.com/v25.0/oauth/access_token?grant_type=fb_exchange_token&client_id={APP_ID}&client_secret={APP_SECRET}&fb_exchange_token={SHORT_LIVED_TOKEN}"
566: ```
567: 
568: Response:
569: ```json
570: {
571:   "access_token": "long_lived_token_here",
572:   "token_type": "bearer",
573:   "expires_in": 5184000
574: }
575: ```
576: 
577: ### Debugging Tokens
578: 
579: Check token validity and permissions:
580: 
581: ```bash
582: curl "https://graph.facebook.com/v25.0/debug_token?input_token={TOKEN_TO_CHECK}&access_token={APP_ID}|{APP_SECRET}"
583: ```
584: 
585: ### Recommended: System User Tokens
586: 
587: For production use, create a System User in Business Manager:
588: 
589: 1. Go to Business Settings > Users > System Users
590: 2. Create a new System User with "Admin" role
591: 3. Assign the ad account to the System User
592: 4. Generate a token with `ads_read` and `ads_management` permissions
593: 
594: System User tokens do not expire.
