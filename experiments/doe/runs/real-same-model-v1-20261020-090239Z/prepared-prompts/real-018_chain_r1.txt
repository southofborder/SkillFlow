18: # Upload-Post API
19: 
20: Post content to multiple social media platforms with a single API call.
21: 
22: ## Overview
23: 
24: One request fans out to every target platform and reports a per-platform result. Accounts are
25: connected once through OAuth in the Upload-Post dashboard, so this skill never handles
26: per-platform developer apps, review processes or token refresh — a single API key covers all
27: 15 platforms.
28: 
29: Four content types are supported: video, photo carousels, text-only posts and documents
30: (LinkedIn). Each can be published immediately, scheduled for a future date, or added to a
31: posting queue.

119: ## Instructions
120: 
121: 1. **Pick the endpoint** by content type — `/upload` for video, `/upload_photos` for photos
122:    and carousels, `/upload_text` for text-only, `/upload_document` for LinkedIn documents.
123: 2. **Set `user`** to the profile name (`$UPLOAD_POST_PROFILE` when set), not a social handle. The profile determines which
124:    connected accounts receive the content.
125: 3. **Repeat `platform[]`** once per target platform.
126: 4. **Add a `title`.** Required for YouTube and Reddit, optional everywhere else. Override it
127:    per platform with `<platform>_title` when the copy should differ.
128: 5. **Set `async_upload=true`** for anything but the smallest files, then poll
129:    `/uploadposts/status?request_id=…` until it reaches a terminal state.
130: 6. **Read the per-platform result** and report which platforms published and which failed —
131:    a request can partially succeed.
132: 
133: To schedule instead of publishing now, add `scheduled_date` (ISO-8601) and optionally
134: `timezone` (IANA). To let Upload-Post pick the next free slot, send `add_to_queue=true`.

390: ## Error Handling
391: 
392: | Code | Meaning |
393: |------|---------|
394: | 400 | Bad request / missing params |
395: | 401 | Invalid API key |
396: | 404 | Resource not found |
397: | 429 | Rate limit / quota exceeded |
398: | 500 | Server error |
399: 
400: The failure modes that actually bite:
401: 
402: - **`401 Invalid or expired token` with a key you know is good** — the key was sent as
403:   `Bearer`. API keys use the `Apikey` scheme. The message is misleading: the key is fine,
404:   the scheme is wrong.
405: - **Some platforms succeeded, others failed** — this is normal, not an exception. Read
406:   `results` per platform and retry only the failures with `retry_request_id` instead of
407:   re-uploading everything.
408: - **The request timed out** — uploads longer than 59 seconds switch to async automatically.
409:   Do not treat a timeout as a failure; poll `/uploadposts/status` with the `request_id`.
410: - **`reached_active_user_cap` on TikTok** — TikTok's daily cap was hit. By default the video
411:   falls back to the TikTok inbox as a draft: `success` is still `true`, the result carries
412:   `fallback_to_inbox: true`, and the id starts with `v_inbox_file`. The video is waiting in
413:   the app, not live.
414: - **Missing title on YouTube or Reddit** — both reject the upload; every other platform
415:   accepts an empty title.
416: - **Duplicate posts after a retry** — send an `Idempotency-Key` header. A retried request
417:   with a matching key returns the existing job rather than publishing twice.
418: 
419: ## Notes
420: 
421: - Videos auto-switch to async if >59s processing time
422: - X long text creates threads unless `x_long_text_as_post=true`
423: - Facebook requires Page ID (personal profiles not supported by Meta)
424: - Instagram/Threads support mixed carousels (photos + videos)

114: ## FFmpeg Re-encoding
115: 
116: If videos fail platform validation, use the FFmpeg endpoint:
117: 
118: ```bash
119: # Convert to H.264 MP4
120: ffmpeg -y -i {input} -c:v libx264 -preset medium -crf 23 -c:a aac -b:a 128k {output}
121: 
122: # Resize to 1080p
123: ffmpeg -y -i {input} -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2" -c:v libx264 -crf 23 {output}
124: 
125: # Convert to 9:16 vertical
126: ffmpeg -y -i {input} -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2" -c:v libx264 -crf 23 {output}
127: ```
