24: # Tushare 金融数据接口
25: 
26: 获取中国 A 股市场和期货市场的实时及历史数据。
27: 
28: ## 前提条件
29: 
30: ### 1. 注册 Tushare 账号
31: 
32: 访问 https://tushare.pro/weborder/#/login?reg=503098 注册账号并获取 API Token。
33: 
34: ### 2. 配置 Token
35: 
36: ```bash
37: # 添加到 ~/.zshrc
38: export TUSHARE_TOKEN="your-api-token-here"
39: ```
40: 
41: 然后执行：
42: ```bash
43: source ~/.zshrc
44: ```
45: 
46: ### 3. 安装依赖
47: 
48: ```bash
49: pip3 install tushare pandas --user
50: ```

170: python3 scripts/market.py fut_daily --ts_code IF.CFX

235: ## 常见问题
236: 
237: **错误：请设置 TUSHARE_TOKEN 环境变量**
238: → 在 `~/.zshrc` 中添加 `export TUSHARE_TOKEN="your-token"` 并执行 `source ~/.zshrc`
239: 
240: **错误：没有数据返回**
241: → 检查股票/期货代码格式是否正确（如：000001.SZ, CU.SHF）
242: 
243: **错误：权限不足**
244: → Tushare 部分接口需要积分或付费权限，请在官网查看接口权限要求
245: 
246: **如何获取股票代码？**
247: ```bash
248: python3 scripts/market.py stock_basic | grep "平安"
249: ```

184: ### 合约代码格式
185: 
186: 期货合约代码由 **品种代码 + 到期年月** 组成：
187: 
188: - `CU2403` - 2024年3月到期的铜合约
189: - `RB2405` - 2024年5月到期的螺纹钢合约
190: - `IF2403` - 2024年3月到期的沪深300股指期货
191: 
192: 主力合约通常用 `.SHF`, `.DCE`, `.CZC`, `.CFX` 后缀表示：
193: - `CU.SHF` - 铜主力合约（上期所）
194: - `M.DCE` - 豆粕主力合约（大商所）
195: - `IF.CFX` - 沪深300主力合约（中金所）
