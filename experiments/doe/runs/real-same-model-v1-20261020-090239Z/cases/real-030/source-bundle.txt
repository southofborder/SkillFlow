6: # Demo Video Creator
7: 
8: Create polished product demo videos by automating browser interactions.
9: 
10: ## Overview
11: 
12: 1. **Plan** the demo sequence (pages, interactions, timing)
13: 2. **Record** frames using Playwright CDP screencast
14: 3. **Encode** to video with FFmpeg
15: 
16: ## Quick Start
17: 
18: ### Prerequisites
19: 
20: - Clawdbot browser running (`browser action=start profile=clawd`)
21: - App accessible via browser (localhost or remote)
22: - FFmpeg installed for encoding
23: 
24: ### Recording Workflow
25: 
26: 1. Start the Clawdbot browser if not running
27: 2. Navigate to the app manually or via `browser action=open`
28: 3. Customize `scripts/record-demo.js` for the target app
29: 4. Run: `node scripts/record-demo.js`
30: 5. Encode: `bash scripts/frames-to-video.sh`
31: 
32: ## Planning a Demo
33: 
34: See `references/demo-planning.md` for guidance on:
35: - Structuring demo sequences
36: - Timing and pacing
37: - Interaction patterns
38: - What makes demos compelling
39: 
40: ## Scripts
41: 
42: ### `scripts/record-demo.js`
43: 
44: Template Playwright script that:
45: - Connects to Clawdbot browser via CDP
46: - Starts screencast capture (JPEG frames)
47: - Executes demo sequence (navigation, clicks, hovers, typing)
48: - Saves frames to output directory
49: 
50: **Customize for each demo:**
51: - `DEMO_SEQUENCES` array - define pages and interactions
52: - `OUTPUT_DIR` - where to save frames
53: - `FRAME_SKIP` - skip every Nth frame (lower = more frames)
54: 
55: ### `scripts/frames-to-video.sh`
56: 
57: FFmpeg encoding script with presets:
58: - `mp4` - H.264, good quality/size balance (default)
59: - `gif` - Animated GIF for embedding
60: - `webm` - VP9, smaller files
61: 
62: Usage: `./frames-to-video.sh [input_dir] [output_name] [format]`
63: 
64: ## Interaction Patterns
65: 
66: ```javascript
67: // Navigation
68: await page.goto('http://localhost/dashboard');
69: await page.waitForTimeout(2000);
70: 
71: // Click element
72: await page.locator('button:has-text("Create")').click();
73: await page.waitForTimeout(500);
74: 
75: // Hover (show tooltips, hover states)
76: await page.locator('.card').first().hover();
77: await page.waitForTimeout(1000);
78: 
79: // Type text
80: await page.locator('input[placeholder="Search"]').fill('query');
81: await page.waitForTimeout(500);
82: 
83: // Press key
84: await page.keyboard.press('Enter');
85: await page.keyboard.press('Escape');
86: 
87: // Scroll
88: await page.evaluate(() => window.scrollBy(0, 300));
89: ```
90: 
91: ## Tips
92: 
93: - **Timing**: 2s on page load, 0.5-1s between interactions, 1.5s to show results
94: - **Frame skip**: Use 3-5 for smooth video, 8-10 for smaller files
95: - **Quality**: 85-90 JPEG quality balances size and clarity
96: - **Resolution**: Browser window size determines output resolution
97: - **Loops**: GIFs should loop seamlessly - end where you started

FILE references/demo-planning.md
1: # Demo Planning Guide
2: 
3: How to plan and structure effective product demos.
4: 
5: ## Demo Structure
6: 
7: ### 1. Hook (5-10 seconds)
8: Start with the most impressive or valuable feature. Grab attention immediately.
9: 
10: ### 2. Core Flow (30-60 seconds)
11: Show the primary use case end-to-end:
12: - User action → System response → Value delivered
13: - Keep it focused on ONE workflow
14: 
15: ### 3. Key Features (15-30 seconds each)
16: Highlight 2-3 differentiating features:
17: - Show, don't tell
18: - Each feature gets its own mini-sequence
19: 
20: ### 4. Polish Moments (throughout)
21: Sprinkle micro-interactions that show quality:
22: - Hover states, transitions, animations
23: - Loading states, feedback
24: - Keyboard shortcuts
25: 
26: ## Timing Guidelines
27: 
28: | Action | Duration |
29: |--------|----------|
30: | Page load | 2-3 seconds |
31: | Read content | 1.5-2 seconds |
32: | Button click | 0.5 seconds |
33: | Dropdown open | 1-1.5 seconds |
34: | Form filling | 0.5s per field |
35: | Show result | 2-3 seconds |
36: | Transition | 0.5 seconds |
37: 
38: **Total demo length:**
39: - Quick teaser: 15-30 seconds
40: - Feature highlight: 45-60 seconds  
41: - Full walkthrough: 2-3 minutes max
42: 
43: ## Interaction Patterns
44: 
45: ### Show Interactivity
46: ```javascript
47: // Hover to reveal tooltips/states
48: await element.hover();
49: await page.waitForTimeout(1000);
50: 
51: // Click to expand/show more
52: await element.click();
53: await page.waitForTimeout(1500);
54: ```
55: 
56: ### Natural Text Input
57: ```javascript
58: // Type slowly for readability
59: await input.type('search query', { delay: 100 });
60: ```
61: 
62: ### Scroll to Reveal
63: ```javascript
64: // Smooth scroll
65: await page.evaluate(() => {
66:   window.scrollBy({ top: 300, behavior: 'smooth' });
67: });
68: await page.waitForTimeout(1000);
69: ```
70: 
71: ### Drag and Drop
72: ```javascript
73: // Simulate drag
74: await page.locator('.draggable').dragTo(page.locator('.dropzone'));
75: ```
76: 
77: ## What Makes Demos Compelling
78: 
79: ### Do
80: - Start at a meaningful state (data pre-populated)
81: - Show real-looking data, not "Test User" and "Lorem ipsum"
82: - Capture hover states, micro-interactions
83: - End on a satisfying completion (success toast, result)
84: - Match the rhythm users would actually experience
85: 
86: ### Don't
87: - Rush through complex features
88: - Show error states (unless that's the point)
89: - Include loading spinners longer than 1 second
90: - Record empty states or onboarding flows (unless relevant)
91: - Leave dropdowns/modals open when moving to next section
92: 
93: ## Demo Checklist
94: 
95: Before recording:
96: - [ ] App in demo-ready state (good data, clean UI)
97: - [ ] Browser window sized appropriately (1280x720 or 1920x1080)
98: - [ ] No notifications, popups, or dev tools visible
99: - [ ] Sequences written and tested manually first
100: 
101: After recording:
102: - [ ] Watch full playback at 1x speed
103: - [ ] Check for timing issues (too fast/slow)
104: - [ ] Verify all interactions are visible
105: - [ ] Trim any dead time at start/end

FILE scripts/frames-to-video.sh
1: #!/bin/bash
2: #
3: # Convert captured frames to video
4: #
5: # Usage: ./frames-to-video.sh [input_dir] [output_name] [format]
6: #
7: # Arguments:
8: #   input_dir   - Directory containing frame_*.jpg files (default: ./demo-frames)
9: #   output_name - Output filename without extension (default: demo)
10: #   format      - mp4, gif, or webm (default: mp4)
11: #
12: # Examples:
13: #   ./frames-to-video.sh
14: #   ./frames-to-video.sh ./demo-frames my-demo mp4
15: #   ./frames-to-video.sh ./frames product-tour gif
16: 
17: set -e
18: 
19: INPUT_DIR="${1:-./demo-frames}"
20: OUTPUT_NAME="${2:-demo}"
21: FORMAT="${3:-mp4}"
22: 
23: # Validate input
24: if [ ! -d "$INPUT_DIR" ]; then
25:     echo "❌ Error: Input directory not found: $INPUT_DIR"
26:     exit 1
27: fi
28: 
29: FRAME_COUNT=$(ls -1 "$INPUT_DIR"/frame_*.jpg 2>/dev/null | wc -l)
30: if [ "$FRAME_COUNT" -eq 0 ]; then
31:     echo "❌ Error: No frame_*.jpg files found in $INPUT_DIR"
32:     exit 1
33: fi
34: 
35: echo "🎬 Converting $FRAME_COUNT frames to $FORMAT..."
36: echo "   Input:  $INPUT_DIR"
37: echo "   Output: ${OUTPUT_NAME}.${FORMAT}"
38: echo ""
39: 
40: case "$FORMAT" in
41:     mp4)
42:         # H.264 MP4 - Good quality, widely compatible
43:         ffmpeg -y -framerate 30 \
44:             -pattern_type glob -i "$INPUT_DIR/frame_*.jpg" \
45:             -c:v libx264 \
46:             -preset medium \
47:             -crf 23 \
48:             -pix_fmt yuv420p \
49:             -movflags +faststart \
50:             "${OUTPUT_NAME}.mp4"
51:         echo "✅ Created ${OUTPUT_NAME}.mp4"
52:         ;;
53:         
54:     gif)
55:         # Animated GIF - Good for embedding, larger files
56:         # Two-pass for better quality: generate palette, then encode
57:         ffmpeg -y -framerate 15 \
58:             -pattern_type glob -i "$INPUT_DIR/frame_*.jpg" \
59:             -vf "fps=15,scale=800:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=256:stats_mode=diff[p];[s1][p]paletteuse=dither=bayer:bayer_scale=5" \
60:             "${OUTPUT_NAME}.gif"
61:         echo "✅ Created ${OUTPUT_NAME}.gif"
62:         ;;
63:         
64:     webm)
65:         # VP9 WebM - Smaller files, good quality
66:         ffmpeg -y -framerate 30 \
67:             -pattern_type glob -i "$INPUT_DIR/frame_*.jpg" \
68:             -c:v libvpx-vp9 \
69:             -crf 30 \
70:             -b:v 0 \
71:             -pix_fmt yuv420p \
72:             "${OUTPUT_NAME}.webm"
73:         echo "✅ Created ${OUTPUT_NAME}.webm"
74:         ;;
75:         
76:     *)
77:         echo "❌ Error: Unknown format '$FORMAT'. Use: mp4, gif, or webm"
78:         exit 1
79:         ;;
80: esac
81: 
82: # Show file info
83: echo ""
84: ls -lh "${OUTPUT_NAME}.${FORMAT}"

FILE scripts/record-demo.js
1: #!/usr/bin/env node
2: /**
3:  * Demo Video Recorder
4:  * 
5:  * Records browser interactions as frames using Playwright CDP screencast.
6:  * Customize DEMO_SEQUENCES for your app.
7:  * 
8:  * Usage: node record-demo.js
9:  * 
10:  * Prerequisites:
11:  * - Clawdbot browser running (browser action=start profile=clawd)
12:  * - App accessible in browser
13:  */
14: 
15: const { chromium } = require('playwright-core');
16: const fs = require('fs');
17: const path = require('path');
18: 
19: // ============== CONFIGURATION ==============
20: 
21: const CONFIG = {
22:   // CDP endpoint for Clawdbot browser
23:   cdpEndpoint: 'http://127.0.0.1:18800',
24:   
25:   // Output settings
26:   outputDir: './demo-frames',
27:   frameSkip: 5,           // Keep every Nth frame (lower = more frames, smoother video)
28:   jpegQuality: 90,        // 1-100, higher = better quality, larger files
29:   
30:   // URL pattern to find the target page (or null to use first page)
31:   targetUrlPattern: 'localhost',
32: };
33: 
34: // ============== DEMO SEQUENCES ==============
35: // Customize this array for your app
36: 
37: const DEMO_SEQUENCES = [
38:   {
39:     name: 'Dashboard Overview',
40:     steps: async (page) => {
41:       await page.goto('http://localhost/dashboard');
42:       await page.waitForTimeout(2000);
43:       
44:       // Hover over a metric card
45:       const card = page.locator('[class*="card"]').first();
46:       if (await card.isVisible()) {
47:         await card.hover();
48:         await page.waitForTimeout(1000);
49:       }
50:       await page.waitForTimeout(1500);
51:     }
52:   },
53:   
54:   {
55:     name: 'Feature Interaction',
56:     steps: async (page) => {
57:       // Example: Click a button, show dropdown
58:       const button = page.locator('button:has-text("Create")').first();
59:       if (await button.isVisible()) {
60:         await button.click();
61:         await page.waitForTimeout(1500);
62:         await page.keyboard.press('Escape');
63:       }
64:       await page.waitForTimeout(1000);
65:     }
66:   },
67:   
68:   {
69:     name: 'Form Input',
70:     steps: async (page) => {
71:       // Example: Type in a search box
72:       const input = page.locator('input[placeholder*="Search"]').first();
73:       if (await input.isVisible()) {
74:         await input.fill('example query');
75:         await page.waitForTimeout(500);
76:         await page.keyboard.press('Enter');
77:         await page.waitForTimeout(2000);
78:       }
79:     }
80:   },
81: ];
82: 
83: // ============== RECORDING ENGINE ==============
84: 
85: async function recordDemo() {
86:   console.log('🎬 Starting demo recording...\n');
87:   
88:   // Connect to browser
89:   const browser = await chromium.connectOverCDP(CONFIG.cdpEndpoint);
90:   const context = browser.contexts()[0];
91:   const pages = context.pages();
92:   
93:   // Find target page
94:   let page = CONFIG.targetUrlPattern
95:     ? pages.find(p => p.url().includes(CONFIG.targetUrlPattern)) || pages[0]
96:     : pages[0];
97:   
98:   console.log(`📍 Recording page: ${page.url()}\n`);
99:   
100:   // Start screencast
101:   const client = await page.context().newCDPSession(page);
102:   await client.send('Page.startScreencast', {
103:     format: 'jpeg',
104:     quality: CONFIG.jpegQuality,
105:     everyNthFrame: 1
106:   });
107:   
108:   const frames = [];
109:   client.on('Page.screencastFrame', async (event) => {
110:     frames.push(Buffer.from(event.data, 'base64'));
111:     await client.send('Page.screencastFrameAck', { sessionId: event.sessionId });
112:   });
113:   
114:   // Execute demo sequences
115:   for (const sequence of DEMO_SEQUENCES) {
116:     console.log(`▶️  ${sequence.name}...`);
117:     try {
118:       await sequence.steps(page);
119:     } catch (err) {
120:       console.warn(`   ⚠️  Error: ${err.message}`);
121:     }
122:   }
123:   
124:   // Stop recording
125:   await client.send('Page.stopScreencast');
126:   console.log(`\n📸 Captured ${frames.length} raw frames`);
127:   
128:   // Save frames (with skip)
129:   const outputDir = path.resolve(CONFIG.outputDir);
130:   if (fs.existsSync(outputDir)) {
131:     fs.rmSync(outputDir, { recursive: true });
132:   }
133:   fs.mkdirSync(outputDir, { recursive: true });
134:   
135:   let savedCount = 0;
136:   for (let i = 0; i < frames.length; i += CONFIG.frameSkip) {
137:     const filename = `frame_${String(savedCount).padStart(5, '0')}.jpg`;
138:     fs.writeFileSync(path.join(outputDir, filename), frames[i]);
139:     savedCount++;
140:   }
141:   
142:   console.log(`💾 Saved ${savedCount} frames to ${outputDir}`);
143:   console.log('\n✅ Recording complete!');
144:   console.log(`\nNext: Run frames-to-video.sh to encode:\n  ./scripts/frames-to-video.sh ${CONFIG.outputDir} demo mp4`);
145: }
146: 
147: recordDemo().catch(console.error);
