70: ## Tools
71: 
72: ### brave_search
73: 
74: Web search returning ranked results with titles, URLs, and descriptions.
75: 
76: ```bash
77: brave_search --query "latest Node.js release" --count 5
78: brave_search --query "TypeScript generics" --extra-snippets true
79: brave_search --query "current weather Copenhagen" --freshness pd
80: brave_search --query "React Server Components" --summary true
81: ```
82: 
83: **Parameters:**
84: - `query` (required) — Search query, supports operators: `site:`, `"exact phrase"`, `-exclude`
85: - `count` — Results to return (1-20, default: 10)
86: - `country` — 2-letter country code (default: `us`)
87: - `freshness` — Date filter: `pd` (24h), `pw` (7 days), `pm` (31 days), `py` (1 year)
88: - `extra-snippets` — Include up to 5 extra text excerpts per result (default: false)
89: - `summary` — Fetch Brave AI summarizer result (default: false)
90: - `offset` — Pagination offset for next page results
91: 
92: **Returns:** Formatted list of results with title, URL, description, optional AI summary, and a hint for next page if `more_results_available`.
93: 
94: ### brave_suggest
95: 
96: Query autosuggest API providing intelligent query autocompletion as users type.
97: 
98: ```bash
99: brave_suggest --query "hello"
100: brave_suggest --query "pyt" --count 5 --country US
101: brave_suggest --query "einstein" --rich true
102: ```
103: 
104: **Parameters:**
105: - `query` (required) — Partial query to get suggestions for
106: - `count` — Number of suggestions (1-10, default: 5)
107: - `country` — 2-letter country code (default: `US`)
108: - `rich` — Include enhanced metadata: titles, descriptions, images, entity detection (default: false, requires paid Autosuggest plan)
109: 
110: **Returns:** List of query suggestions, optionally with rich metadata. Results are cached for 60 seconds.
111: 
112: **Best Practices:**
113: - Implement debouncing (150-300ms) to avoid excessive API calls as users type
114: - Load suggestions asynchronously without blocking the UI
115: 
116: ### brave_spellcheck
117: 
118: Spell checking and query correction for search queries.
119: 
120: ```bash
121: brave_spellcheck --query "articifial inteligence"
122: brave_spellcheck --query "hello" --country US
123: ```
124: 
125: **Parameters:**
126: - `query` (required) — Query to check for spelling errors
127: - `country` — 2-letter country code (default: `US`)
128: 
129: **Returns:** "Did you mean:" suggestion, or confirms no correction needed. Uses dedicated `BRAVE_SPELLCHECK_API_KEY` if available, falls back to `BRAVE_SEARCH_API_KEY`.
130: 
131: 
132: ### brave_answers
133: 
134: AI-powered answers grounded in live web search with inline citations.
135: 
136: ```bash
137: brave_answers --query "How does React Server Components work?"
138: brave_answers --query "Compare Postgres vs MySQL for OLAP" --enable-research true
139: brave_answers --query "Latest Python release notes" --enable-citations true
140: brave_answers --query "Who is Albert Einstein" --enable-entities true
141: ```
142: 
143: **Parameters:**
144: - `query` (required) — Question or topic to research
145: - `country` — Target country for search context (default: `us`)
146: - `enable-citations` — Include inline source citations (default: true)
147: - `enable-research` — Multi-search deep research mode (default: false)
148: - `enable-entities` — Include entity information in responses (default: false, streaming required)
149: - `stream` — Enable streaming output (default: true — required for citations/entities/research)
150: 
151: **Returns:** AI answer with cited sources extracted from the response, plus token usage and cost breakdown.
152: 
153: > ⚠️ **Citations, entities, and research mode require streaming (`--stream true`, which is the default).** If you disable streaming with `--stream false`, citations and entity data will not be available.
154: 
155: **Streaming mode output:**
156: - Text streams progressively to stdout
157: - Entities streamed inline as `<enum_item>` tags are parsed
158: - **Entities mentioned** section printed at the end (v4.2.0)
159: - Sources printed at the end (sorted by citation number)
160: - Token usage and cost breakdown included
161: 
162: **Non-streaming fallback:** Use `--stream false` for simpler output at the cost of losing citations and entity data.

179: ## Technical Details
180: 
181: ### Architecture
182: 
183: The skill uses a shared `utils.js` module containing:
184: - `parseArgs()` — CLI argument parser
185: - `fetchWithRetry()` — fetch with exponential backoff retry on 429 and 5xx
186: - `createCache()` — in-memory TTL cache (used by `brave_suggest`)
187: 
188: ### brave_search.js
189: 
190: The core search script with the following optimizations:
191: - **Parallel summary fetch:** When `--summary` is enabled, the summary key is extracted from the search response and fetched in parallel with the search results
192: - **Pagination hint:** Response includes a hint for the next page offset when `more_results_available` is true
193: - **Rate limit handling:** Retries on 429 (honors `Retry-After` header) and 5xx (exponential backoff)
194: 
195: ### brave_answers.js v4.2.0
196: 
197: The AI answers script supports two modes:
198: - **Streaming (default):** Progressive output with real-time entity extraction, deduplicated citations, token usage, and cost breakdown
199: - **Non-streaming:** Full citation and entity extraction from batch response via `parseCitations()` and `parseEntities()`
200: 
201: Key changes in v4.2.0:
202: - **Entity extraction:** Streaming mode parses `<enum_item>` tags incrementally — entity names are streamed inline as they are parsed, and a consolidated **Entities mentioned** section is printed at the end with URL and citation count per entity
203: - **Citation deduplication:** Duplicate source URLs are deduplicated so each source is cited only once (sorted by citation number)
204: - **Non-streaming mode (v4.2.0):** Full `parseCitations()` and `parseEntities()` applied to the batch response content, so citations and entities are extracted even without streaming
205: 
206: ### brave_suggest.js
207: 
208: The autosuggest script with the following optimizations:
209: - **In-memory cache:** 60-second TTL cache keyed by `query|count|country|rich` — deduplicates rapid successive calls
210: - **Key fallback chain:** `AUTOSUGGEST_API_KEY` → `BRAVE_AUTOSUGGEST_API_KEY` → `BRAVE_SEARCH_API_KEY`
211: 
212: ### brave_answers streaming
213: 
214: When streaming is enabled (`stream: true`):
215: - SSE chunks are parsed in real-time
216: - Citations are collected and printed at end (sorted by citation number)
217: - Entity items (`<enum_item>`) are parsed incrementally — streamed inline and collected for the **Entities mentioned** section
218: - Usage block (`<usage>`) parsed and displayed with token counts and total cost
219: 
220: ## Security & Packaging Notes
221: 
222: - This skill only calls Brave official endpoints under `https://api.search.brave.com/res/v1`.
223: - It requires `BRAVE_SEARCH_API_KEY` and `BRAVE_ANSWERS_API_KEY` (keep them in `.env`, not inline in commands/chats).
224: - Optionally accepts `AUTOSUGGEST_API_KEY` or `BRAVE_AUTOSUGGEST_API_KEY` for autosuggest.
225: - It does not request persistent/system privileges and does not modify system config.
226: - All scripts are Node.js 18+ native (no external dependencies).

17: function stripHtml(text) {
18:   if (!text) return '';
19:   return text
20:     .replace(/<[^>]+>/g, '')
21:     .replace(/&lt;/g, '<')
22:     .replace(/&gt;/g, '>')
23:     .replace(/&amp;/g, '&')
24:     .replace(/&#x27;/g, "'")
25:     .replace(/&#x2F;/g, '/')
26:     .replace(/&#39;/g, "'")
27:     .replace(/&quot;/g, '"')
28:     .trim();

31: // ─── Citation & entity parsing ────────────────────────────────────────────────
32: 
33: function parseCitations(text) {
34:   const sources = [];
35:   const seen = new Set();
36: 
37:   const citationRegex = /<citation>([\s\S]*?)<\/citation>/g;
38:   let match;
39:   while ((match = citationRegex.exec(text)) !== null) {
40:     try {
41:       const citation = JSON.parse(match[1]);
42:       if (citation.url && !seen.has(citation.url)) {
43:         seen.add(citation.url);
44:         sources.push({
45:           url: citation.url,
46:           title: citation.title || citation.url,
47:           snippet: citation.snippet || '',
48:           number: citation.number,
49:         });
50:       }
51:     } catch {
52:       // ignore malformed citation
53:     }
54:   }
55: 
56:   const cleanText = text
57:     .replace(/<citation>[\s\S]*?<\/citation>/g, '')
58:     .replace(/\n{3,}/g, '\n\n')
59:     .trim();
60: 
61:   return { cleanText, sources };
62: }
63: 
64: function parseEntities(text) {
65:   const entities = [];
66:   const entityRegex = /<enum_item>([\s\S]*?)<\/enum_item>/g;
67:   let match;
68:   while ((match = entityRegex.exec(text)) !== null) {
69:     try {
70:       const entity = JSON.parse(match[1]);
71:       if (entity.name) {
72:         entities.push({
73:           name: entity.name,
74:           href: entity.href || '',
75:           originalTokens: entity.original_tokens || '',
76:           citations: entity.citations || [],
77:         });
78:       }
79:     } catch {
80:       // ignore malformed entity
81:     }
82:   }
83:   return entities;
84: }

88: async function streamAnswer(query, country, enableCitations, enableResearch, enableEntities) {
89:   const apiKey = getApiKey();
90:   if (!apiKey) {
91:     console.error('Error: BRAVE_ANSWERS_API_KEY environment variable not set.');
92:     console.error('Get your key at: https://api-dashboard.search.brave.com');
93:     process.exit(1);
94:   }
95: 
96:   const body = {
97:     model: 'brave',
98:     messages: [{ role: 'user', content: query }],
99:     stream: true,
100:     extra_body: {
101:       country,
102:       language: 'en',
103:       enable_citations: enableCitations,
104:       enable_research: enableResearch,
105:       enable_entities: enableEntities,
106:     },
107:   };
108: 
109:   const res = await fetchWithRetry(`${BASE_URL}/chat/completions`, {
110:     method: 'POST',
111:     headers: {
112:       'Content-Type': 'application/json',
113:       'Accept': 'application/json',
114:       'X-Subscription-Token': apiKey,
115:     },
116:     body: JSON.stringify(body),
117:   });
118: 
119:   if (!res.ok) {
120:     const errBody = await res.text();
121:     console.error(`Brave Answers API error ${res.status}: ${errBody}`);
122:     process.exit(1);
123:   }
124: 
125:   // Collect all chunks for final formatting
126:   let fullContent = '';
127:   let usageLine = '';
128:   let sources = [];
129:   let seenUrls = new Set();
130: 
131:   const reader = res.body.getReader();
132:   const decoder = new TextDecoder();
133:   let buffer = '';
134: 
135:   process.stdout.write('**Query:** ' + query + '\n\n');
136: 
137:   while (true) {
138:     const { done, value } = await reader.read();
139:     if (done) break;
140: 
141:     buffer += decoder.decode(value, { stream: true });
142:     const lines = buffer.split('\n');
143:     buffer = lines.pop(); // keep incomplete line
144: 
145:     for (const line of lines) {
146:       if (!line.startsWith('data: ')) continue;
147:       const data = line.slice(6).trim();
148:       if (data === '[DONE]' || data === '') continue;
149: 
150:       let chunk;
151:       try {
152:         chunk = JSON.parse(data);
153:       } catch {
154:         continue;
155:       }
156: 
157:       const delta = chunk.choices?.[0]?.delta?.content || '';
158:       if (!delta) continue;
159: 
160:       // Handle special tags
161:       if (delta.startsWith('<citation>')) {
162:         const citationText = delta.replace(/<citation>/g, '').replace(/<\/citation>/g, '');
163:         try {
164:           const citation = JSON.parse(citationText);
165:           if (citation.url && !seenUrls.has(citation.url)) {
166:             seenUrls.add(citation.url);
167:             sources.push({
168:               url: citation.url,
169:               title: citation.title || citation.url,
170:               snippet: citation.snippet || '',
171:               number: citation.number,
172:             });
173:           }
174:         } catch {
175:           // partial citation — skip
176:         }
177:         fullContent += delta;
178:       } else if (delta.startsWith('<usage>')) {
179:         usageLine = delta;
180:         fullContent += delta;
181:       } else if (delta.startsWith('<enum_item>')) {
182:         // Format and stream entity item immediately
183:         const entityText = delta.replace('<enum_item>', '').replace('</enum_item>', '');
184:         try {
185:           const entity = JSON.parse(entityText);
186:           const label = entity.original_tokens || entity.name || '';
187:           const href = entity.href || '';
188:           if (label) {
189:             process.stdout.write(` *${label}*`);
190:             if (href) process.stdout.write(`(${href})`);
191:             process.stdout.write(' ');
192:           }
193:         } catch {
194:           // malformed entity tag — stream as plain text
195:           process.stdout.write(delta);
196:         }
197:         fullContent += delta;
198:       } else {
199:         // Plain text — stream it immediately
200:         process.stdout.write(delta);
201:         fullContent += delta;
202:       }
203:     }
204:   }
205: 
206:   process.stdout.write('\n');
207: 
208:   // Entities section
209:   const entities = parseEntities(fullContent);
210:   if (entities.length > 0) {
211:     process.stdout.write('\n**Entities mentioned:**\n');
212:     entities.forEach(e => {
213:       const citeNote = e.citations.length > 0
214:         ? ` (cited in ${e.citations.length} place${e.citations.length > 1 ? 's' : ''})`
215:         : '';
216:       if (e.href) {
217:         process.stdout.write(`- [${e.name}](${e.href})${citeNote}\n`);
218:       } else {
219:         process.stdout.write(`- ${e.name}${citeNote}\n`);
220:       }
221:     });
222:   }
223: 
224:   // Print sources at the end
225:   if (sources.length > 0) {
226:     sources.sort((a, b) => (a.number || 0) - (b.number || 0));
227:     process.stdout.write('\n**Sources:**\n');
228:     sources.forEach(s => {
229:       process.stdout.write(`${s.number || '?'}. [${s.title}](${s.url})\n`);
230:       if (s.snippet) process.stdout.write(`   > ${s.snippet}\n`);
231:     });
232:   }
233: 
234:   // Parse and print usage
235:   if (usageLine) {
236:     try {
237:       const usageJson = usageLine
238:         .replace('<usage>', '')
239:         .replace('</usage>', '');
240:       const usage = JSON.parse(usageJson);
241:       const totalTokens = (usage['X-Request-Tokens-In'] || 0) + (usage['X-Request-Tokens-Out'] || 0);
242:       process.stdout.write(
243:         `\n*Tokens: ${totalTokens} ` +
244:         `(in: ${usage['X-Request-Tokens-In'] || 0}, out: ${usage['X-Request-Tokens-Out'] || 0})*\n`
245:       );
246:       const totalCost = usage['X-Request-Total-Cost'];
247:       if (totalCost !== undefined && totalCost !== null) {
248:         process.stdout.write(`*Total cost: $${parseFloat(totalCost).toFixed(5)}*\n`);
249:       }
250:     } catch {
251:       // ignore malformed usage tag
252:     }
253:   }
254: }

299:   const content = data.choices?.[0]?.message?.content || '';

301: 
302:   const { cleanText, sources } = parseCitations(content);
303:   const entities = parseEntities(content);
304:   const lines = [];
305: 
306:   lines.push(`**Query:** ${query}\n`);
307:   lines.push(cleanText);
308: 
309:   if (entities.length > 0) {
310:     lines.push('\n**Entities mentioned:**');
311:     entities.forEach(e => {
312:       if (e.href) {
313:         lines.push(`- [${e.name}](${e.href})`);
314:       } else {
315:         lines.push(`- ${e.name}`);
316:       }
317:     });
318:   }
319: 
320:   if (sources.length > 0) {
321:     lines.push('\n**Sources:**');
322:     sources.sort((a, b) => (a.number || 0) - (b.number || 0));
323:     sources.forEach(s => {
324:       lines.push(`${s.number || '?'}. [${s.title}](${s.url})`);
325:       if (s.snippet) lines.push(`   > ${s.snippet}`);
326:     });
327:   }
328: 
329:   const usage = data.usage;
330:   if (usage) {
331:     lines.push(`\n*Tokens: ${usage.total_tokens} (prompt: ${usage.prompt_tokens}, completion: ${usage.completion_tokens})*`);
332:   }
333:

4: /**
5:  * Parse CLI args from process.argv
6:  * Supports: --key value, --flag (true), --key=value
7:  */
8: function parseArgs(argv) {
9:   const args = {};
10:   for (let i = 2; i < argv.length; i++) {
11:     if (argv[i].startsWith('--')) {
12:       const arg = argv[i].slice(2);
13:       if (arg.includes('=')) {
14:         const [key, val] = arg.split('=', 2);
15:         args[key] = val;
16:       } else {
17:         const val = argv[i + 1] && !argv[i + 1].startsWith('--') ? argv[++i] : 'true';
18:         args[arg] = val;
19:       }
20:     }
21:   }
22:   return args;
23: }

25: /**
26:  * Fetch with retry logic.
27:  * Retries on 429 (Retry-After delay) and 5xx errors.
28:  * @param {string} url
29:  * @param {object} options
30:  * @param {number} [maxRetries=3]
31:  */
32: async function fetchWithRetry(url, options, maxRetries = 3) {
33:   let lastError;
34: 
35:   for (let attempt = 0; attempt <= maxRetries; attempt++) {
36:     try {
37:       const res = await fetch(url, options);
38: 
39:       if (res.status === 429) {
40:         const retryAfter = parseInt(res.headers.get('Retry-After') || '5', 10);
41:         const delay = retryAfter * 1000;
42:         if (attempt < maxRetries) {
43:           await sleep(delay);
44:           continue;
45:         }
46:       }
47: 
48:       if (res.status >= 500 && attempt < maxRetries) {
49:         await sleep(500 * Math.pow(2, attempt));
50:         continue;
51:       }
52: 
53:       return res;
54:     } catch (err) {
55:       lastError = err;
56:       if (attempt < maxRetries) {
57:         await sleep(500 * Math.pow(2, attempt));
58:       }
59:     }
60:   }
61: 
62:   throw lastError;
63: }

65: function sleep(ms) {
66:   return new Promise(resolve => setTimeout(resolve, ms));
67: }

69: /**
70:  * Simple in-memory cache with TTL.
71:  * Use as: cache.get(key) or cache.set(key, value, ttlMs)
72:  */
73: function createCache() {
74:   const store = new Map();
75:   return {
76:     get(key) {
77:       const entry = store.get(key);
78:       if (!entry) return null;
79:       if (Date.now() > entry.expires) {
80:         store.delete(key);
81:         return null;
82:       }
83:       return entry.value;
84:     },
85:     set(key, value, ttlMs = 60_000) {
86:       store.set(key, { value, expires: Date.now() + ttlMs });
87:     },
88:     clear() {
89:       store.clear();
90:     },
91:   };
92: }
