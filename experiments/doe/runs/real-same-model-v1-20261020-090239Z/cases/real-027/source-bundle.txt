8: # SSH Essentials
9: 
10: Secure Shell (SSH) for remote access and secure file transfers.
11: 
12: ## Basic Connection
13: 
14: ### Connecting
15: ```bash
16: # Connect with username
17: ssh user@hostname
18: 
19: # Connect to specific port
20: ssh user@hostname -p 2222
21: 
22: # Connect with verbose output
23: ssh -v user@hostname
24: 
25: # Connect with specific key
26: ssh -i ~/.ssh/id_rsa user@hostname
27: 
28: # Connect and run command
29: ssh user@hostname 'ls -la'
30: ssh user@hostname 'uptime && df -h'
31: ```
32: 
33: ### Interactive use
34: ```bash
35: # Connect with forwarding agent
36: ssh -A user@hostname
37: 
38: # Connect with X11 forwarding (GUI apps)
39: ssh -X user@hostname
40: ssh -Y user@hostname  # Trusted X11
41: 
42: # Escape sequences (during session)
43: # ~. - Disconnect
44: # ~^Z - Suspend SSH
45: # ~# - List forwarded connections
46: # ~? - Help
47: ```
48: 
49: ## SSH Keys
50: 
51: ### Generating keys
52: ```bash
53: # Generate RSA key
54: ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
55: 
56: # Generate ED25519 key (recommended)
57: ssh-keygen -t ed25519 -C "your_email@example.com"
58: 
59: # Generate with custom filename
60: ssh-keygen -t ed25519 -f ~/.ssh/id_myserver
61: 
62: # Generate without passphrase (automation)
63: ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_deploy
64: ```
65: 
66: ### Managing keys
67: ```bash
68: # Copy public key to server
69: ssh-copy-id user@hostname
70: 
71: # Copy specific key
72: ssh-copy-id -i ~/.ssh/id_rsa.pub user@hostname
73: 
74: # Manual key copy
75: cat ~/.ssh/id_rsa.pub | ssh user@hostname 'cat >> ~/.ssh/authorized_keys'
76: 
77: # Check key fingerprint
78: ssh-keygen -lf ~/.ssh/id_rsa.pub
79: 
80: # Change key passphrase
81: ssh-keygen -p -f ~/.ssh/id_rsa
82: ```
83: 
84: ### SSH agent
85: ```bash
86: # Start ssh-agent
87: eval $(ssh-agent)
88: 
89: # Add key to agent
90: ssh-add ~/.ssh/id_rsa
91: 
92: # List keys in agent
93: ssh-add -l
94: 
95: # Remove key from agent
96: ssh-add -d ~/.ssh/id_rsa
97: 
98: # Remove all keys
99: ssh-add -D
100: 
101: # Set key lifetime (seconds)
102: ssh-add -t 3600 ~/.ssh/id_rsa
103: ```

105: ## Port Forwarding & Tunneling
106: 
107: ### Local port forwarding
108: ```bash
109: # Forward local port to remote
110: ssh -L 8080:localhost:80 user@hostname
111: # Access via: http://localhost:8080
112: 
113: # Forward to different remote host
114: ssh -L 8080:database.example.com:5432 user@jumphost
115: # Access database through jumphost
116: 
117: # Multiple forwards
118: ssh -L 8080:localhost:80 -L 3306:localhost:3306 user@hostname
119: ```
120: 
121: ### Remote port forwarding
122: ```bash
123: # Forward remote port to local
124: ssh -R 8080:localhost:3000 user@hostname
125: # Remote server can access localhost:3000 via its port 8080
126: 
127: # Make service accessible from remote
128: ssh -R 9000:localhost:9000 user@publicserver
129: ```
130: 
131: ### Dynamic port forwarding (SOCKS proxy)
132: ```bash
133: # Create SOCKS proxy
134: ssh -D 1080 user@hostname
135: 
136: # Use with browser or apps
137: # Configure SOCKS5 proxy: localhost:1080
138: 
139: # With Firefox
140: firefox --profile $(mktemp -d) \
141:   --preferences "network.proxy.type=1;network.proxy.socks=localhost;network.proxy.socks_port=1080"
142: ```
143: 
144: ### Background tunnels
145: ```bash
146: # Run in background
147: ssh -f -N -L 8080:localhost:80 user@hostname
148: 
149: # -f: Background
150: # -N: No command execution
151: # -L: Local forward
152: 
153: # Keep alive
154: ssh -o ServerAliveInterval=60 -L 8080:localhost:80 user@hostname
155: ```

157: ## Configuration
158: 
159: ### SSH config file (`~/.ssh/config`)
160: ```
161: # Simple host alias
162: Host myserver
163:     HostName 192.168.1.100
164:     User admin
165:     Port 2222
166: 
167: # With key and options
168: Host production
169:     HostName prod.example.com
170:     User deploy
171:     IdentityFile ~/.ssh/id_prod
172:     ForwardAgent yes
173:     
174: # Jump host (bastion)
175: Host internal
176:     HostName 10.0.0.5
177:     User admin
178:     ProxyJump bastion
179: 
180: Host bastion
181:     HostName bastion.example.com
182:     User admin
183: 
184: # Wildcard configuration
185: Host *.example.com
186:     User admin
187:     ForwardAgent yes
188:     
189: # Keep connections alive
190: Host *
191:     ServerAliveInterval 60
192:     ServerAliveCountMax 3
193: ```
194: 
195: ### Using config
196: ```bash
197: # Connect using alias
198: ssh myserver
199: 
200: # Jump through bastion automatically
201: ssh internal
202: 
203: # Override config options
204: ssh -o "StrictHostKeyChecking=no" myserver
205: ```

207: ## File Transfers
208: 
209: ### SCP (Secure Copy)
210: ```bash
211: # Copy file to remote
212: scp file.txt user@hostname:/path/to/destination/
213: 
214: # Copy file from remote
215: scp user@hostname:/path/to/file.txt ./local/
216: 
217: # Copy directory recursively
218: scp -r /local/dir user@hostname:/remote/dir/
219: 
220: # Copy with specific port
221: scp -P 2222 file.txt user@hostname:/path/
222: 
223: # Copy with compression
224: scp -C large-file.zip user@hostname:/path/
225: 
226: # Preserve attributes (timestamps, permissions)
227: scp -p file.txt user@hostname:/path/
228: ```
229: 
230: ### SFTP (Secure FTP)
231: ```bash
232: # Connect to SFTP server
233: sftp user@hostname
234: 
235: # Common SFTP commands:
236: # pwd          - Remote working directory
237: # lpwd         - Local working directory
238: # ls           - List remote files
239: # lls          - List local files
240: # cd           - Change remote directory
241: # lcd          - Change local directory
242: # get file     - Download file
243: # put file     - Upload file
244: # mget *.txt   - Download multiple files
245: # mput *.jpg   - Upload multiple files
246: # mkdir dir    - Create remote directory
247: # rmdir dir    - Remove remote directory
248: # rm file      - Delete remote file
249: # exit/bye     - Quit
250: 
251: # Batch mode
252: sftp -b commands.txt user@hostname
253: ```
254: 
255: ### Rsync over SSH
256: ```bash
257: # Sync directory
258: rsync -avz /local/dir/ user@hostname:/remote/dir/
259: 
260: # Sync with progress
261: rsync -avz --progress /local/dir/ user@hostname:/remote/dir/
262: 
263: # Sync with delete (mirror)
264: rsync -avz --delete /local/dir/ user@hostname:/remote/dir/
265: 
266: # Exclude patterns
267: rsync -avz --exclude '*.log' --exclude 'node_modules/' \
268:   /local/dir/ user@hostname:/remote/dir/
269: 
270: # Custom SSH port
271: rsync -avz -e "ssh -p 2222" /local/dir/ user@hostname:/remote/dir/
272: 
273: # Dry run
274: rsync -avz --dry-run /local/dir/ user@hostname:/remote/dir/
275: ```

277: ## Security Best Practices
278: 
279: ### Hardening SSH
280: ```bash
281: # Disable password authentication (edit /etc/ssh/sshd_config)
282: PasswordAuthentication no
283: PubkeyAuthentication yes
284: 
285: # Disable root login
286: PermitRootLogin no
287: 
288: # Change default port
289: Port 2222
290: 
291: # Use protocol 2 only
292: Protocol 2
293: 
294: # Limit users
295: AllowUsers user1 user2
296: 
297: # Restart SSH service
298: sudo systemctl restart sshd
299: ```
300: 
301: ### Connection security
302: ```bash
303: # Check host key
304: ssh-keygen -F hostname
305: 
306: # Remove old host key
307: ssh-keygen -R hostname
308: 
309: # Strict host key checking
310: ssh -o StrictHostKeyChecking=yes user@hostname
311: 
312: # Use specific cipher
313: ssh -c aes256-ctr user@hostname
314: ```

316: ## Troubleshooting
317: 
318: ### Debugging
319: ```bash
320: # Verbose output
321: ssh -v user@hostname
322: ssh -vv user@hostname  # More verbose
323: ssh -vvv user@hostname  # Maximum verbosity
324: 
325: # Test connection
326: ssh -T user@hostname
327: 
328: # Check permissions
329: ls -la ~/.ssh/
330: # Should be: 700 for ~/.ssh, 600 for keys, 644 for .pub files
331: ```
332: 
333: ### Common issues
334: ```bash
335: # Fix permissions
336: chmod 700 ~/.ssh
337: chmod 600 ~/.ssh/id_rsa
338: chmod 644 ~/.ssh/id_rsa.pub
339: chmod 644 ~/.ssh/authorized_keys
340: 
341: # Clear known_hosts entry
342: ssh-keygen -R hostname
343: 
344: # Disable host key checking (not recommended)
345: ssh -o StrictHostKeyChecking=no user@hostname
346: ```

348: ## Advanced Operations
349: 
350: ### Jump hosts (ProxyJump)
351: ```bash
352: # Connect through bastion
353: ssh -J bastion.example.com user@internal.local
354: 
355: # Multiple jumps
356: ssh -J bastion1,bastion2 user@final-destination
357: 
358: # Using config (see Configuration section above)
359: ssh internal  # Automatically uses ProxyJump
360: ```
361: 
362: ### Multiplexing
363: ```bash
364: # Master connection
365: ssh -M -S ~/.ssh/control-%r@%h:%p user@hostname
366: 
367: # Reuse connection
368: ssh -S ~/.ssh/control-user@hostname:22 user@hostname
369: 
370: # In config:
371: # ControlMaster auto
372: # ControlPath ~/.ssh/control-%r@%h:%p
373: # ControlPersist 10m
374: ```
375: 
376: ### Execute commands
377: ```bash
378: # Single command
379: ssh user@hostname 'uptime'
380: 
381: # Multiple commands
382: ssh user@hostname 'cd /var/log && tail -n 20 syslog'
383: 
384: # Pipe commands
385: cat local-script.sh | ssh user@hostname 'bash -s'
386: 
387: # With sudo
388: ssh -t user@hostname 'sudo command'
389: ```

391: ## Tips
392: 
393: - Use SSH keys instead of passwords
394: - Use `~/.ssh/config` for frequently accessed hosts
395: - Enable SSH agent forwarding carefully (security risk)
396: - Use ProxyJump for accessing internal networks
397: - Keep SSH client and server updated
398: - Use fail2ban or similar to prevent brute force
399: - Monitor `/var/log/auth.log` for suspicious activity
400: - Use port knocking or VPN for additional security
401: - Backup your SSH keys securely
402: - Use different keys for different purposes
