1: # Token Optimizer for OpenClaw & Hermes
2: 
3: [![Version](https://img.shields.io/badge/version-4.1.1-brightgreen.svg)](CHANGELOG.md)
4: [![MissionDeck](https://img.shields.io/badge/MissionDeck-ai-blueviolet)](https://missiondeck.ai)
5: [![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE.txt)
6: 
7: Built by [MissionDeck.ai](https://missiondeck.ai) · [GitHub](https://github.com/Asif2BD/OpenClaw-Token-Optimizer) · [ClawHub](https://clawhub.ai/asif2bd/skills/openclaw-token-optimizer)
8: 
9: **Find where your AI agent may be wasting tokens—and get a clear, safe improvement plan.**
10: 
11: Large instructions, poorly matched models and repetitive AI tasks can all add overhead.
12: Token Optimizer helps your OpenClaw or Hermes agent investigate those opportunities and
13: explain what is worth changing. It does not silently change your setup or promise savings
14: it has not measured.
15: 
16: ## Start by asking your agent
17: 
18: Once the skill is installed, say:
19: 
20: > “Use Token Optimizer to check my setup and suggest the three most useful improvements.”
21: 
22: You can also ask:
23: 
24: - “Are my scheduled tasks using AI when a simple script would do?”
25: - “Which instruction files are taking up the most context?”
26: - “Review my model choices for everyday tasks.”
27: - “Check my Hermes profile for unnecessary recurring AI work.”
28: 
29: **You do not need to begin with terminal commands.** A tool-enabled agent uses its known
30: host runtime, current agent or active profile to perform read-only checks. It asks only
31: when information is missing or ambiguous. The skill cannot add terminal access to an
32: agent that does not have it.
33: 
34: ## What you will get
35: 
36: - **A clear verdict:** what was inspected and what deserves attention.
37: - **Prioritized suggestions:** a few useful next steps, with evidence and caveats.
38: - **No surprise changes:** your models, schedules and instruction files stay untouched.
39: - **Honest limits:** missing spending data stays unknown, not a misleading zero.
40: 
41: For example, it may flag an agent task running every few minutes for review, or identify
42: large instruction files. Neither proves waste by itself; your agent explains the trade-off
43: before recommending a change. Actual savings require a comparable before/after measurement.
44: 
45: ## One skill, two platforms
46: 
47: **OpenClaw:** inspects the native model catalog/status and scheduled jobs. Optional known
48: config files add deeper checks. Recognizes agent tasks, commands, heartbeats and system events.
49: 
50: **Hermes Agent:** reads the active profile's configuration and scheduled jobs. Traces model
51: choices including saved creation-time defaults, skips paused jobs, and recognizes no-agent
52: scripts. This is file-based auditing—not native model discovery or authentication testing.
53: 
54: **Both:** can inspect selected instruction sizes, duplicate content and supplied usage
55: figures. Model recommendations need a user policy and sufficient availability evidence.
56: 
57: The agent selects the runtime from trusted context. If both platforms are installed and
58: no active runtime is known, it asks rather than guessing. Your chosen profile takes priority.
59: 
60: ## Install
61: 
62: Ask your agent to install the ClawHub skill **openclaw-token-optimizer** through its normal
63: skill installer, or use the ClawHub CLI:
64: 
65: ```bash
66: clawhub install openclaw-token-optimizer --version 4.1.1
67: ```
68: 
69: The slug stays the same for both platforms. Keep the bundled scripts and references with
70: SKILL.md. Python 3.10+ is required; YAML input additionally needs PyYAML, usually available
71: in the Hermes Python environment. Nothing is installed automatically by the audit.
72: 
73: OpenClaw is tested on 2026.9.4. Hermes compatibility is tested against a pinned upstream
74: cron-storage implementation in an isolated profile, without starting an agent or scheduler.
75: See [Hermes compatibility](references/HERMES.md) and [agent quick start](references/QUICKSTART.md).
76: 
77: ## Frequently asked before starting
78: 
79: **Will this reduce my bill automatically?** No. It finds candidates for improvement; actual
80: savings depend on the changes you choose and how they perform on matched workloads.
81: 
82: **Will it break my working setup?** The bundled analyzer does not edit configuration,
83: activate models, execute jobs or restart anything. OpenClaw read commands may contact
84: configured services or update native caches.
85: 
86: **Do I need to prepare exports?** Not for a normal audit when the host has the required
87: read tools and known profile. Exports are an alternative for offline use; Hermes's separate
88: model-routing function requires normalized catalog/status evidence.
89: 
90: **Does it measure my complete API spending?** Not automatically. Native usage collection
91: and budget alerts are not included. Missing or incomplete data is labeled clearly.

96: steps for an ordinary audit.

98: ## Advanced: run the OpenClaw audit yourself
99: 
100: ```bash
101: python3 scripts/optimizer.py audit --live --agent YOUR_AGENT --json
102: ```
103: 
104: Replace `YOUR_AGENT` with your actual agent ID. To include config-level findings, provide
105: an explicit local JSON file with `--config /path/to/config.json`. Its contents are not echoed.
106: 
107: Generate a review plan with the same inputs:
108: 
109: ```bash
110: python3 scripts/optimizer.py plan --live --agent YOUR_AGENT --json
111: ```
112: 
113: The plan contains review actions, not automatic fixes. Model absence and missing metadata
114: are reasons to investigate—not proof that a model or job is broken.
115: 
116: ## Choose a model using your policy
117: 
118: ```bash
119: python3 scripts/optimizer.py route --live --agent YOUR_AGENT \
120:   --policy assets/config.example.json --tier research --json
121: ```
122: 
123: The bundled policy illustrates routine, balanced, research, coding and background tiers.
124: Adapt it to your available providers and quality/cost preferences. It is not a universal
125: ranking or live pricing database. Recommendations never activate a model.
126: 
127: Add `--image`, `--tools` or `--context-tokens 8000` when the task requires those capabilities.
128: Unknown capability metadata blocks the recommendation. In particular, many native catalogs
129: do not expose `supportsTools`; lack of that field does not mean the model lacks tools.
130: A separately authorized exact-route canary is needed before activation.
131: 
132: ## Inspect context size and duplicate instructions
133: 
134: ```bash
135: python3 scripts/optimizer.py context /path/to/SOUL.md /path/to/AGENTS.md --json
136: ```
137: 
138: Only explicitly named files are read. Reports show character counts, approximate tokens
139: (character count divided by four), and duplicate content. They do not print file contents.
140: Use OpenClaw's native `/context list` and `/context detail` to establish actual injected
141: context. Do not remove essential agent instructions based on file size alone.
142: 
143: ## Check supplied usage without false zeros
144: 
145: ```bash
146: python3 scripts/optimizer.py budget --json
147: python3 scripts/optimizer.py budget --usage usage.json --limit 10 --json
148: ```
149: 
150: `usage.json` accepts an aggregate such as `{"costUSD":2.5,"complete":false}`.
151: Without data, the result is unknown/null. **Automatic native usage ingestion, daily/weekly
152: alerts and measured billing comparisons are not included in v4.1.1.**
153: 
154: ## Offline audit and input formats
155: 
156: ```bash
157: python3 scripts/optimizer.py audit --catalog catalog.json --status status.json \
158:   --config config.json --jobs jobs.json --json
159: ```
160: 
161: Native JSON shapes:
162: 
163: - Catalog: `{ "models": [{ "key": "provider/model", "available": true, "input": "text+image", "contextWindow": 32000 }] }`
164: - Status: `{ "allowed": ["provider/model"], "auth": { "missingProvidersInUse": [], "modelRouteIssues": [] } }`
165: - Config: `{ "agents": { "defaults": { "model": "provider/model" }, "entries": {} } }`
166: - Automations: `{ "jobs": [] }`
167: - Optional normalized sessions via `--sessions`: `{ "sessions": [{ "agentId": "example", "model": "provider/model" }] }`
168: 
169: Inputs must be JSON, not JSON5. Missing inputs and paginated automation responses are
170: explicitly marked as incomplete coverage. Tool capability may be supplied as
171: `supportsTools: true` only when backed by trustworthy metadata.
172: 
173: ## Safety and operational limits
174: 
175: The pure analysis core has no I/O. Explicit live mode invokes fixed native read commands:
176: 
177: - `openclaw --version`
178: - `openclaw models list --agent ID --all --json`
179: - `openclaw models status --agent ID --json`
180: - `openclaw cron list --all --json` (audit/plan only)
181: 
182: These commands may contact your configured Gateway or providers and update native caches.
183: The optimizer does not run paid inference probes, upload reports, install other software,
184: or write your configuration. Native reads have a 45-second timeout; inputs have an 8 MiB
185: size limit. Selected identifiers and basenames can still be private—review reports before sharing.
186: 
187: Exit **0** means analysis completed, not that no issues exist. Exit **2** means invalid
188: input or a failed native read. Reports go to stdout; `--json` supports downstream tooling.
189: `plan` intentionally emits no schema-blind patches. See [SECURITY.md](SECURITY.md).
190: 
191: ## Automation support
192: 
193: Native **heartbeat** and **systemEvent** jobs are now recognized. The optimizer no longer
194: reports them as unknown or subjects them to agent-turn-only model/timeout/context checks.
195: Unknown future payload kinds remain visible. Recognition is not a full audit of those
196: jobs' effective runtime settings.

FILE SECURITY.md
1: # Security policy — OpenClaw Token Optimizer 4.1.1
2: 
3: ## Trust boundary
4: 
5: This is a local read-only analysis package. It contains Python standard-library scripts
6: and a shell launcher. Hermes YAML parsing additionally uses optional PyYAML. There are no install hooks, telemetry,
7: credential collectors, dynamic code evaluation, or automatic config changes.
8: 
9: ## File behavior
10: 
11: - `optimizer_core.py`: pure analysis functions; no files, network or processes.
12: - `optimizer.py`: reads explicitly supplied JSON/context files and prints selected analysis.
13:   For the OpenClaw runtime, `--live` invokes only fixed `openclaw --version`, `openclaw models list`, `models status`, and `cron list` read
14:   commands with `subprocess.run`, argv lists, no shell, and a timeout. The installed OpenClaw
15:   executable and configured Gateway/providers are trusted dependencies. They may perform
16:   network requests; therefore we do NOT claim that live mode is offline or network-free.
17: - `optimize.sh`: resolves its own directory and delegates arguments to optimizer.py.
18: - Four old script names: migration shims to explicit v4 subcommands; no old writes remain.
19: - `assets/`: public example policy, empty patch set, review templates; never auto-installed.
20: - `references/PROVIDERS.md`: policy guidance, not executable setup or credential handling.
21: - Markdown/license/manifest files: documentation and file integrity metadata only.
22: 
23: ## Data handling
24: 
25: Raw config/auth records, job commands/prompts and context contents are not printed.
26: Only selected findings, model/agent identifiers and file basenames appear. Those selected
27: identifiers can themselves be private: inspect reports before sharing. Errors deliberately
28: withhold raw native stderr and invalid input values. No report upload occurs.
29: 
30: Explicit config input can contain secrets; the file is read locally, never modified.
31: Use sanitized exports where practical. Do not publish real config, session dumps or reports.
32: Native status is held in process memory only. Live reads may update OpenClaw's own caches
33: or logs; this package does not promise the native executable has zero side effects.
34: 
35: ## Review and integrity
36: 
37: The subprocess adapter may warrant scanner scrutiny: inspect its fixed argv call sites.
38: A checksum manifest is not proof of safety and cannot guarantee a third-party review pass.
39: Do not dismiss a scanner finding as a false positive without examining its evidence.
40: 
41: Run `python3 -m unittest discover -s tests -v` from GitHub source and
42: `sha256sum -c SHA256SUMS.txt` against the distributed package. Tests cover malformed inputs,
43: missing usage, auth/capability gates, no-shell execution, and read-only behavior.
44: No paid canary is run by the package. Catalog flags alone are not inference proof.
45: 
46: Maintainer: [Asif2BD](https://github.com/Asif2BD) · [MissionDeck.ai](https://missiondeck.ai)
47: 
48: ## Hermes file adapter
49: 
50: Only explicitly selected profile config/jobs files are read. JSON uses the standard library;
51: YAML uses optional PyYAML safe_load (never unsafe constructors). The adapter does not read
52: .env or credentials, import Hermes, execute jobs, start schedulers or make network requests.
53: Selected model identifiers may appear in reports; raw prompts/scripts/config do not.

2: import json
3: from pathlib import Path

7: MAX_BYTES = 8 * 1024 * 1024

9: def read_config(path):
10:     p = Path(path)
11:     if p.stat().st_size > MAX_BYTES:
12:         raise ValueError('Config exceeds limit')
13:     text = p.read_text()
14:     if p.suffix.lower() == '.json':
15:         data = json.loads(text)
16:     else:
17:         try:
18:             import yaml
19:         except ImportError as exc:
20:             raise ValueError('Hermes YAML requires PyYAML; use JSON export or Hermes Python environment') from exc
21:         try:
22:             data = yaml.safe_load(text)
23:         except yaml.YAMLError as exc:
24:             raise ValueError('Invalid YAML; raw data withheld') from exc
25:     if not isinstance(data, dict):
26:         raise ValueError('Config must be an object')
27:     return data
28: 
29: def resolve_job(job, config, model_env=None):
30:     model_cfg = config.get('model') or {}
31:     fleet = config.get('cron') or {}
32:     if not isinstance(fleet, dict) or not isinstance(model_cfg, (dict, str)):
33:         raise ValueError('Unsupported Hermes model/cron shape')
34:     global_model = model_cfg.get('default') if isinstance(model_cfg, dict) else model_cfg
35:     global_provider = model_cfg.get('provider') if isinstance(model_cfg, dict) else None
36:     def choose(pairs):
37:         for source, value in pairs:
38:             if isinstance(value, str) and value.strip():
39:                 return safe_id(value.strip()), source
40:         return None, 'unknown'
41:     model, model_source = choose([('job',job.get('model')),('cron',fleet.get('model')),
42:         ('snapshot',job.get('model_snapshot')),('explicit_environment',model_env),('global_config',global_model)])
43:     provider, provider_source = choose([('job',job.get('provider')),('cron',fleet.get('model_provider')),
44:         ('snapshot',job.get('provider_snapshot')),('global_config',global_provider)])
45:     return {'model':model,'modelSource':model_source,'provider':provider,'providerSource':provider_source}
46: 
47: def audit_hermes(config, jobs, model_env=None, config_present=True, jobs_present=True):
48:     if not isinstance(jobs, list) or any(not isinstance(j, dict) for j in jobs):
49:         raise ValueError('Hermes jobs must be an array of objects')
50:     out=[]; summaries=[]; enabled=0; scripts=0
51:     for index, job in enumerate(jobs,1):
52:         if job.get('enabled',True) is False or job.get('state')=='paused':
53:             continue
54:         enabled += 1
55:         label=f'Automation #{index}'
56:         no_agent=job.get('no_agent',False)
57:         if not isinstance(no_agent,bool):
58:             raise ValueError('no_agent must be a boolean')
59:         if no_agent:
60:             scripts += 1
61:             summaries.append({'index':index,'mode':'no_agent','llmInference':False})
62:             if not isinstance(job.get('script'),str) or not job['script'].strip():
63:                 out.append(finding('hermes_script_missing','warning',f'{label}: no_agent job has no script.'))
64:             continue
65:         resolved=resolve_job(job,config,model_env)
66:         summaries.append({'index':index,'mode':'agent','resolution':resolved})
67:         if not resolved['model']:
68:             out.append(finding('hermes_model_unknown','warning',f'{label}: no model found in supplied file evidence; environment/runtime may differ.'))
69:         elif resolved['modelSource']=='snapshot':
70:             out.append(finding('hermes_snapshot_model','info',f'{label}: retains its creation-time model snapshot, not the current global default.'))

79:             out.append(finding('hermes_delivery_inherited','info',f'{label}: delivery is not explicit in the supplied job.'))
