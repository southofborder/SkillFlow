4:   A Yahoo Finance (yfinance) powered financial analysis tool.
5:   Get real-time quotes, generate high-resolution charts with moving averages + indicators (RSI/MACD/Bollinger/VWAP/ATR),

8: 
9: # Stock Information Explorer
10: 
11: This skill fetches OHLCV data from Yahoo Finance via `yfinance` and computes technical indicators **locally** (no API key required).
12: 
13: ## Commands
14: 
15: ### 1) Real-time Quotes (`price`)
16: ```bash
17: uv run --script scripts/yf.py price TSLA
18: # shorthand
19: uv run --script scripts/yf.py TSLA
20: ```
21: 
22: ### 2) Fundamental Summary (`fundamentals`)
23: ```bash
24: uv run --script scripts/yf.py fundamentals NVDA
25: ```
26: 
27: ### 3) ASCII Trend (`history`)
28: ```bash
29: uv run --script scripts/yf.py history AAPL 6mo
30: ```
31: 
32: ### 4) Professional Chart (`pro`)
33: Generates a high-resolution PNG chart. By default it includes **Volume** and **Moving Averages (MA5/20/60)**.
34: 
35: ```bash
36: # candle (default)
37: uv run --script scripts/yf.py pro 000660.KS 6mo
38: 
39: # line
40: uv run --script scripts/yf.py pro 000660.KS 6mo line
41: ```
42: 
43: #### Indicators (optional)
44: Add flags to include indicator panels/overlays.
45: 
46: ```bash
47: uv run --script scripts/yf.py pro TSLA 6mo --rsi --macd --bb
48: uv run --script scripts/yf.py pro TSLA 6mo --vwap --atr
49: ```
50: 
51: - `--rsi` : RSI(14)
52: - `--macd`: MACD(12,26,9)
53: - `--bb`  : Bollinger Bands(20,2)
54: - `--vwap`: VWAP (cumulative for the selected range)
55: - `--atr` : ATR(14)
56: 
57: ### 5) One-shot Report (`report`) ⭐
58: Prints a compact text summary (price + fundamentals + indicator signals) and automatically generates a **Pro chart with BB + RSI + MACD**.
59: 
60: ```bash
61: uv run --script scripts/yf.py report 000660.KS 6mo
62: # output includes: CHART_PATH:/tmp/<...>.png
63: ```
64: 
65: ## Ticker Examples
66: - US stocks: `AAPL`, `NVDA`, `TSLA`
67: - KR stocks: `005930.KS`, `000660.KS`
68: - Crypto: `BTC-USD`, `ETH-KRW`
69: - Forex: `USDKRW=X`
70: 
71: ## Notes / Limitations
72: - Indicators are **computed locally** from price data (Yahoo does not reliably provide precomputed indicator series).
73: - Data quality may vary by ticker/market (e.g., missing volume for some symbols).

29: def calc_rsi(close: pd.Series, window: int = 14) -> pd.Series:
30:     delta = close.diff()
31:     gain = delta.clip(lower=0)
32:     loss = -delta.clip(upper=0)
33:     avg_gain = gain.ewm(alpha=1/window, adjust=False, min_periods=window).mean()
34:     avg_loss = loss.ewm(alpha=1/window, adjust=False, min_periods=window).mean()
35:     rs = avg_gain / avg_loss.replace(0, pd.NA)
36:     rsi = 100 - (100 / (1 + rs))
37:     return rsi

40: def calc_macd(close: pd.Series, fast: int = 12, slow: int = 26, signal: int = 9):
41:     ema_fast = close.ewm(span=fast, adjust=False, min_periods=fast).mean()
42:     ema_slow = close.ewm(span=slow, adjust=False, min_periods=slow).mean()
43:     macd = ema_fast - ema_slow
44:     sig = macd.ewm(span=signal, adjust=False, min_periods=signal).mean()
45:     hist = macd - sig
46:     return macd, sig, hist

49: def calc_bbands(close: pd.Series, window: int = 20, n_std: float = 2.0):
50:     ma = close.rolling(window=window, min_periods=window).mean()
51:     std = close.rolling(window=window, min_periods=window).std(ddof=0)
52:     upper = ma + n_std * std
53:     lower = ma - n_std * std
54:     return upper, ma, lower

57: def calc_vwap(df: pd.DataFrame) -> pd.Series:
58:     # VWAP over the provided window (cumulative over the selected period)
59:     typical_price = (df['High'] + df['Low'] + df['Close']) / 3
60:     vol = df['Volume'].fillna(0)
61:     tpv = (typical_price * vol).cumsum()
62:     vwap = tpv / vol.cumsum().replace(0, pd.NA)
63:     return vwap

66: def calc_atr(df: pd.DataFrame, window: int = 14) -> pd.Series:
67:     high = df['High']
68:     low = df['Low']
69:     close = df['Close']
70:     prev_close = close.shift(1)
71:     tr = pd.concat([
72:         (high - low),
73:         (high - prev_close).abs(),
74:         (low - prev_close).abs(),
75:     ], axis=1).max(axis=1)
76:     atr = tr.ewm(alpha=1/window, adjust=False, min_periods=window).mean()
77:     return atr
