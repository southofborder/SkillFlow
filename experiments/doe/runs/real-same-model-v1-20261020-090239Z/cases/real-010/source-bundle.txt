44: export WECHAT_APP_ID=your_wechat_app_id
45: export WECHAT_APP_SECRET=your_wechat_app_secret

47:

54: 1. 登录微信公众号后台：https://mp.weixin.qq.com/
55: 2. 设置与开发 → 基本配置 → 开发者ID(AppID) 和 开发者密码(AppSecret)
56: 3. 添加服务器 IP 到白名单：设置与开发 → 基本配置 → IP白名单
57:

122: ## 🛠️ 故障排查
123: 
124: ### 常见问题
125: 
126: **1. 错误：`Error: 未能找到文章封面`**
127: - **原因**：frontmatter 缺少 `cover` 字段
128: - **解决**：确保 frontmatter 包含 `title` 和 `cover`
129: 
130: **2. 错误：`Error: 45166 (IP地址不在白名单中)`**
131: - **原因**：运行机器的 IP 未添加到微信白名单
132: - **解决**：登录公众号后台添加 IP 到白名单
133: 
134: **3. 发布成功但看不到文章？**
135: - **原因**：文章在草稿箱，需要审核发布
136: - **解决**：草稿箱 → 选中文章 → 发布
137: 
138: **4. 图片上传失败？**
139: - **原因**：网络图片无法访问或格式不支持
140: - **解决**：使用本地图片或检查网络连接
141: 
142: 查看完整故障排查指南：[references/troubleshooting.md](references/troubleshooting.md)

272: 
273: **错误信息：** `wenyan: command not found`

275: **解决方法：**
276: ```bash
277: npm install -g @wenyan-md/cli
278: ```

282: **错误信息：** `WECHAT_APP_ID is required`

286: export WECHAT_APP_ID=your_wechat_app_id
287: export WECHAT_APP_SECRET=your_wechat_app_secret

290: 或在 `~/.zshrc` / `~/.bashrc` 中永久添加。

88: ## 4. ❌ Frontmatter 缺失（最常见！）
89: 
90: **错误信息：**
91: ```
92: Error: 未能找到文章封面
93: ```
94: 
95: **原因：** Markdown 文件缺少必需的 frontmatter（特别是 `title` 字段）。
96: 
97: **⚠️ 重要：** wenyan-cli **强制要求** frontmatter，必须在 Markdown 文件顶部添加！
98: 
99: **解决方法：**
100: 
101: **方案 1：有封面图**
102: ```markdown
103: ---
104: title: 你的文章标题
105: cover: /path/to/cover.jpg
106: ---
107: 
108: # 正文开始
109: ...
110: ```
111: 
112: **方案 2：无封面图（推荐，正文有图片即可）**
113: ```markdown
114: ---
115: title: 你的文章标题
116: ---
117: 
118: # 正文
119: 
120: ![配图](https://example.com/image.jpg)  # 正文图片会自动上传
121: 
122: 内容...
123: ```
124: 
125: **⚠️ 关键点：**
126: - `title` 字段是**必须的**，缺少会报错 "未能找到文章封面"
127: - `cover` 字段可选：如果正文中有图片，wenyan 会自动使用第一张图作为封面
128: - frontmatter 必须在文件最顶部，前面不能有空行或其他内容
129: - frontmatter 使用三个短横线 `---` 包围
130: 
131: **错误示例（会报错）：**
132: ```markdown
133: # 我的文章
134: 
135: 没有 frontmatter，wenyan 会报错！
136: ```

162:    ```bash
163:    file /path/to/image.jpg
164:    ```
165: 
166: 3. **压缩图片（如果过大）：**
167:    ```bash
168:    # 使用 ImageMagick
169:    convert large.jpg -quality 80 -resize 1200x compressed.jpg
170:    ```
171: 
172: 4. **测试网络图片：**

1: #!/usr/bin/env bash
2: # wechat-publisher: 发布 Markdown 到微信公众号草稿箱
3: # Usage: ./publish.sh <markdown-file> [theme] [highlight]
4: 
5: set -e
6: 
7: # 颜色定义
8: RED='\033[0;31m'
9: GREEN='\033[0;32m'
10: YELLOW='\033[1;33m'
11: NC='\033[0m' # No Color
12: 
13: # 默认配置
14: DEFAULT_THEME="lapis"
15: DEFAULT_HIGHLIGHT="solarized-light"
16: TOOLS_MD="$HOME/.openclaw/workspace/TOOLS.md"
17: 
18: # 检查 wenyan-cli 是否安装
19: check_wenyan() {
20:     if ! command -v wenyan &> /dev/null; then
21:         echo -e "${RED}❌ wenyan-cli 未安装！${NC}"
22:         echo -e "${YELLOW}正在安装 wenyan-cli...${NC}"
23:         npm install -g @wenyan-md/cli
24:         if [ $? -eq 0 ]; then
25:             echo -e "${GREEN}✅ wenyan-cli 安装成功！${NC}"
26:         else
27:             echo -e "${RED}❌ 安装失败！请手动运行: npm install -g @wenyan-md/cli${NC}"
28:             exit 1
29:         fi
30:     fi
31: }
32: 
33: # 从 TOOLS.md 读取环境变量
34: load_credentials() {
35:     if [ -z "$WECHAT_APP_ID" ] || [ -z "$WECHAT_APP_SECRET" ]; then
36:         if [ -f "$TOOLS_MD" ]; then
37:             echo -e "${YELLOW}📖 从 TOOLS.md 读取凭证...${NC}"
38:             export WECHAT_APP_ID=$(grep "export WECHAT_APP_ID=" "$TOOLS_MD" | head -1 | sed 's/.*export WECHAT_APP_ID=//' | tr -d ' ')
39:             export WECHAT_APP_SECRET=$(grep "export WECHAT_APP_SECRET=" "$TOOLS_MD" | head -1 | sed 's/.*export WECHAT_APP_SECRET=//' | tr -d ' ')
40:         fi
41:     fi
42: }
43: 
44: # 检查环境变量
45: check_env() {
46:     load_credentials
47:     
48:     if [ -z "$WECHAT_APP_ID" ] || [ -z "$WECHAT_APP_SECRET" ]; then
49:         echo -e "${RED}❌ 环境变量未设置！${NC}"
50:         echo -e "${YELLOW}请在 TOOLS.md 中添加微信公众号凭证：${NC}"
