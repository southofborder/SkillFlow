The conditional reductions can be implemented conceptually as this proposed chain:

```text
Model-invisible local request component:
  read request.json
  retain the original term value
  include each optional value exactly when its member is present
  omit each missing optional argument, consistently with query.yaml

Search:
  invoke index.search once with those selected original values

Model-invisible local response component:
  write the original response.total value to local count.txt
  return the original response.items value unchanged
```

This proposal preserves the required query value, optional values, member-presence conditions, omission semantics, call cardinality, post-search file side effect, and unchanged return. It introduces no fuzzy expansion, normalization, inferred validation stage, retries, or deletion. Its reduction is specifically model access to the request and response; it does not eliminate the search recipient’s required arguments, the required file contents, or the required result.
