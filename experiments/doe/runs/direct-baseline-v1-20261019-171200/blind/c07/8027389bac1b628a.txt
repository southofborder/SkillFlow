The static control flow is a single ordered sequence:

1. **Acquire the ticket:** load the full, unchanged ticket as `original_v1` into local ephemeral memory (`SKILL.md:8`; `CONTRACTS.md:24–28`).
2. **Create the replacement version:** compute `redacted_v2 = mask_fields(original_v1)`. This creates a fresh object; it leaves `original_v1` unchanged, replaces exactly the two specified field values, and preserves all other fields and values (`SKILL.md:9`; `CONTRACTS.md:30–34`).
3. **Compose externally:** pass `redacted_v2` and the specified style to `draft_model.compose`; receive `draft_v3` after the model returns (`SKILL.md:10`; `CONTRACTS.md:36–40`).
4. **Assign a local alias:** set `working_ticket = redacted_v2` after the call. This neither changes `original_v1` nor changes the earlier request (`SKILL.md:11`).
5. **Clean locally:** compute `final_v4` by replacing any exact occurrences of the original email and session-key strings in `draft_v3` with their replacement strings. Other characters are unchanged (`SKILL.md:12`; `CONTRACTS.md:42–46`).
6. **Deliver:** show exactly `final_v4` to the requester through one `user.reply` call (`SKILL.md:13`; `CONTRACTS.md:50`).
