# Google Search flow

- **Documented entry and setup.** The Skill describes Google PSE search for live information, documentation, or research when built-in `web_search` is unavailable (`skill/SKILL.md:1-8`). Setup requires enabling Custom Search API, obtaining an API key and CX ID, and storing `GOOGLE_API_KEY` and `GOOGLE_CSE_ID` in a workspace `.env` (`skill/SKILL.md:10-19`). The example supplies these variables directly to `python3 skills/google-search/scripts/search.py "OpenClaw documentation"` (`skill/SKILL.md:24-28`). The workflow section contains only a placeholder, so further workflow obligations are unavailable (`skill/SKILL.md:21-22`).

- **Independent callable entry.** `google_search(query, api_key, cse_id, num_results=5)` accepts its arguments directly; it does not acquire credentials from the environment. It sends an HTTP GET through imported `requests` to `https://www.googleapis.com/customsearch/v1`, with `q=query`, `key=api_key`, `cx=cse_id`, and `num=num_results` (`skill/scripts/search.py:3,6-14`). The resulting response comes from that external service, not from calculation over the parameters alone. The function checks HTTP status, then decodes and returns the response JSON. Request, status-check, or decoding exceptions propagate to its caller; a failed status check prevents JSON decoding and return (`skill/scripts/search.py:14-16`).

- **CLI entry and ordered conditions.** Execution under `__main__` first tests `len(sys.argv) < 2`. If true, it prints usage naming `google_search.py` and exits with status 1 (`skill/scripts/search.py:18-21`). Otherwise, `sys.argv[1]` becomes the query; when `len(sys.argv) > 2`, `sys.argv[2]` is converted with `int`, otherwise the count is 5. This conversion occurs before credential acquisition and outside the later exception handler (`skill/scripts/search.py:23-24,34-39`).

- **Credential acquisition and dispatch.** Imported `os` reads `GOOGLE_API_KEY` and `GOOGLE_CSE_ID` from the process environment. If either acquired value is falsy, the CLI prints the credential error and exits with status 1; no search request occurs (`skill/scripts/search.py:4,26-32`). Otherwise, the CLI calls `google_search` with the actual query, acquired API key, acquired CSE ID, and selected count (`skill/scripts/search.py:34-35`).

- **Returned versions and recipients.** On success, the function’s decoded JSON return becomes CLI-local `results`; imported `json` serializes that value with indentation 2, and `print` delivers the serialized text to standard output (`skill/scripts/search.py:2,16,35-36`). An `Exception` raised within the try block instead supplies the caught value `e`; the handler prints its string in an error message and exits with status 1. This exception value is distinct from a successful API result (`skill/scripts/search.py:34-39`). Imported `sys` supplies CLI arguments and exit operations (`skill/scripts/search.py:1,19-24,32,39`).
