## Description:

Speak responses aloud on macOS using the built-in `say` command when user input indicates Voice Wake/voice recognition.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xadenryan](https://clawhub.ai/user/xadenryan)

### License/Terms of Use:


## Use Case:

Users working with voice-recognition or Voice Wake sessions on macOS use this skill to have an agent speak eligible responses aloud locally with the built-in `say` command while leaving non-triggered conversations text-only.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Spoken responses may be overheard by people nearby.

Mitigation: Use the skill only in suitable environments and avoid speaking sensitive details in shared or public spaces.
