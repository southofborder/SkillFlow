## Known Risks and Mitigations:

Risk: The skill enables automatic capture and reinjection of conversation data with limited consent and safety controls.

Mitigation: Use a dedicated brain per project, disable autoCapture and autoContext unless explicitly needed, and avoid use in conversations containing secrets or regulated data.

Risk: The release security verdict is suspicious and installation uses external pip or npm packages.

Mitigation: Review carefully before installing and verify the exact pip or npm packages and versions before running install or build commands.
