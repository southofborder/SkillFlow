## Description:

Multi search engine integration with 17 engines (8 CN + 9 Global), advanced search operators, time filters, site search, privacy engines, and WolframAlpha knowledge queries; no API keys required.

This skill is ready for commercial/non-commercial use.

## Publisher:

[solomon4github](https://clawhub.ai/user/solomon4github)

### License/Terms of Use:

MIT

## Use Case:

Developers, researchers, and external agent users use this skill to choose search engines and construct search URLs for web research, site-specific searches, filetype searches, privacy-focused searches, and WolframAlpha knowledge queries.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search queries may be sent to the selected third-party search engine.

Mitigation: Do not use the skill for secrets, credentials, private internal names, sensitive personal data, or other confidential queries.

Risk: Safe-search-off options and advanced operators can expose sensitive or policy-violating content.

Mitigation: Keep safe-search settings aligned with policy and review dual-use queries before executing them.
