## Description:

The skill guides agents to verify, evaluate, and respond rigorously to code review feedback before implementing suggestions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[chenleiyanquan](https://clawhub.ai/user/chenleiyanquan)

### License/Terms of Use:


## Use Case:

Developers and engineering agents use this skill when receiving code review feedback that may be unclear, incomplete, or technically questionable. It helps them clarify scope, verify suggestions against the codebase, push back when needed, and implement reviewed changes one item at a time.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may make agents more skeptical of external review feedback and more likely to ask for clarification or push back on technically unsound suggestions.

Mitigation: Review the skill's response rules before deployment and align them with the team's code review norms.

Risk: The skill discourages conventional gratitude or performative agreement in review replies, which may conflict with some collaboration styles.

Mitigation: Adjust or approve the tone constraints during installation if the target environment expects different review etiquette.
