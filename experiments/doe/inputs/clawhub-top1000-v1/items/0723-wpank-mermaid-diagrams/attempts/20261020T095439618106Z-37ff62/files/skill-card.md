Global

## Known Risks and Mitigations:

Risk: Mutable install commands, mutable branch URLs, global npm installs, broad CDN imports, and Mermaid click links can change behavior or introduce outbound network behavior.

Mitigation: Prefer pinned versions or reviewed local copies, and use trusted destinations for Mermaid links and CDN examples.

Risk: Generated diagrams can be syntactically invalid, overly complex, stale, or misleading if accepted without review.

Mitigation: Validate diagrams in the target renderer and review them for accuracy, readable scope, labeled relationships, and current system behavior before publishing.
