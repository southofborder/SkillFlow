This skill is ready for commercial/non-commercial use.

Developers, DBAs, data engineers, and quantitative researchers use this skill to look up DolphinDB concepts, locate relevant documentation, and draft or review DolphinDB scripts for database, streaming, and backtesting work.

## Known Risks and Mitigations:

Risk: Examples may include default administrator credentials.

Mitigation: Replace all sample credentials and avoid default administrator accounts before using guidance in a real system.

Risk: Examples may include destructive shell, filesystem, database, replication, or deployment commands.

Mitigation: Manually review commands before running them, keep shell execution disabled unless needed, and test changes in a controlled environment with backups.

Risk: The skill is documentation-only, so generated answers may need adaptation for a specific DolphinDB deployment.

Mitigation: Check generated code and configuration against the installed DolphinDB version, cluster topology, permissions, and operational policies.
