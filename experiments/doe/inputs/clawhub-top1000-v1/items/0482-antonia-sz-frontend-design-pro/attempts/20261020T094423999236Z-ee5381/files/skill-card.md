## Description:

Frontend Design Pro is an opinionated frontend design guidance skill that helps agents audit, polish, and critique UI and frontend code using typography, color, spacing, motion, interaction, and UX writing rules.

This skill is ready for commercial/non-commercial use.

## Publisher:

[antonia-sz](https://clawhub.ai/user/antonia-sz)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and design-focused agents use this skill to improve generated UI and frontend code, review components for design quality, and apply concrete design refinements through commands such as /audit, /polish, and /critique.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill applies opinionated frontend design defaults that may conflict with an existing product design system.

Mitigation: Review recommendations against the active design system and disable or override the skill's preferences where project standards differ.

Risk: Design review guidance could introduce misleading or unsuitable UI changes if accepted without review.

Mitigation: Review generated UI changes for accessibility, responsiveness, brand fit, and implementation correctness before deployment.
