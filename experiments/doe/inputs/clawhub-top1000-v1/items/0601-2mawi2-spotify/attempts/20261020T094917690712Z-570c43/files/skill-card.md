## Description:

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to let an agent control Spotify playback, track navigation, and volume on macOS through the Spotify CLI and AppleScript.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generic music requests could cause unintended Spotify playback or volume changes on macOS.

Mitigation: Confirm Spotify is the intended service before allowing the agent to run playback or volume commands.
