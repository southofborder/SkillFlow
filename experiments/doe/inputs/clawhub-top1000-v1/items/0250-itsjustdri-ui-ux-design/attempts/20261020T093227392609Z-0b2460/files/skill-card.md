## Use Case:

Developers and designers use this skill to plan, review, and implement modern web and mobile interfaces with mobile-first layouts, accessible interaction patterns, design-system choices, and Tailwind CSS plus Shadcn/ui component guidance.

## Known Risks and Mitigations:

Risk: The skill includes unpinned npm scaffolding commands that may install changing package versions.

Mitigation: Pin exact create-next-app and shadcn versions, run setup in a clean project or container, and avoid production credentials or sensitive environment variables during setup.
