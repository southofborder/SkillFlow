## Description:

Fetches Douyin hot list and search trend data across popular videos, challenges, music, and related content, returning titles, popularity values, links, and cover images when available.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: Security evidence flags an unsafe helper that can execute shell commands if given a crafted argument.

Mitigation: Prefer the documented scripts/douyin.js command, avoid untrusted arguments to scripts/get-hot-trend.js, and constrain any caller-provided limits to numeric values.

Risk: Security evidence notes under-documented Telegram-oriented output with a hard-coded chat_id.

Mitigation: Use the Telegram or cron workflow only when intentionally needed, and review or replace the chat_id before deployment.

Risk: The Douyin web endpoint response structure and access controls may change or throttle frequent requests.

Mitigation: Handle fetch failures, review output quality before relying on rankings, and run requests at a reasonable frequency.
