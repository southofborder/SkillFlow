## Use Case:

External users and developers use this skill to capture, organize, search, and maintain personal knowledge in an Ensue-backed second brain after reviewing drafts and confirming writes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Memory entries and searches are sent to Ensue as a remote store.

Mitigation: Install only if you are comfortable using Ensue for this memory data, and avoid saving secrets, credentials, private file paths, or highly sensitive personal material.

Risk: Create, update, and delete operations can change stored knowledge.

Mitigation: Review drafts and requested changes carefully before confirming any create, update, or delete action.

Risk: Low-quality or time-sensitive entries can make later retrieval misleading.

Mitigation: Keep saved entries evergreen, concrete, and written for future retrieval, including the reason the knowledge matters.
