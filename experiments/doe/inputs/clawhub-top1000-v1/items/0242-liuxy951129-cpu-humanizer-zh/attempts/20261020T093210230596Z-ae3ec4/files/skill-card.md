## Description:

Humanizer-zh helps agents revise Chinese text to reduce common AI-writing patterns and make drafts sound more natural while preserving meaning and tone.

This skill is ready for commercial/non-commercial use.

## Publisher:

[liuxy951129-cpu](https://clawhub.ai/user/liuxy951129-cpu)

### License/Terms of Use:


## Use Case:

Writers, editors, reviewers, and developers use this skill to revise Chinese drafts by identifying common AI-writing patterns and replacing them with more natural phrasing while preserving meaning and intended tone.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The recommended unpinned npx install path can install from a moving source.

Mitigation: Review the exact source before installation and prefer a manual or git-clone installation pinned to a trusted commit.

Risk: The skill rewrites user-provided text and may change meaning, emphasis, or tone.

Mitigation: Review revised text before publication and use the skill only on text or files you are comfortable having rewritten.
