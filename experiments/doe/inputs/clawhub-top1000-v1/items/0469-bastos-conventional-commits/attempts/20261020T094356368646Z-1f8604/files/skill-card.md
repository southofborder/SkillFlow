## Description:

Format commit messages using the Conventional Commits specification.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bastos](https://clawhub.ai/user/bastos)

### License/Terms of Use:

MIT

## Use Case:

Developers and engineering teams use this skill to draft or review git commit messages in the Conventional Commits format for clearer history, changelog automation, and semantic versioning workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may steer commit-message discussions toward Conventional Commits even when a repository does not require that format.

Mitigation: Confirm the repository's contribution or release policy before applying the suggested format.
