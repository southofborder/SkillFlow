## Use Case:

Developers and engineers use Git Helper to ask an agent for common Git repository tasks such as checking status, pulling, pushing, managing branches, and viewing logs.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: Git operations such as push, pull, and branch management can change repository state or interact with remotes.

Mitigation: Review the target repository, current branch, and remote before asking the agent to run state-changing Git commands.
