## Use Case:

Developers, students, and interview candidates use Code Mentor for interactive programming lessons, code review, debugging guidance, algorithm practice, project mentoring, and design pattern exploration. It supports Python and JavaScript teaching workflows with optional local scripts for code analysis, complexity analysis, and test running.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Saved learning progress can retain sensitive details if a user includes secrets or proprietary code in session notes.

Mitigation: Do not paste secrets or proprietary code into saved progress notes; review or clear artifact/references/user-progress/learning_log.md before sharing the skill package.

Risk: The optional test runner executes local project code and dependencies.

Mitigation: Run the test utility only on trusted projects, preferably in an isolated environment, and review dependencies before execution.

Risk: Programming guidance, code review feedback, or generated examples may be incorrect or incomplete.

Mitigation: Review suggested code and commands before use, and validate changes with tests and normal engineering review.
