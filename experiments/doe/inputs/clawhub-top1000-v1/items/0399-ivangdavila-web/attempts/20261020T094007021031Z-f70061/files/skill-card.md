## Known Risks and Mitigations:

Risk: Deployment, DNS, hosting, or environment variable guidance can affect live projects if applied without review.

Mitigation: Review proposed commands and configuration changes in a staging environment before applying them to production projects.

Risk: Client-exposed environment variables or unsafe DOM patterns can leak secrets or create security issues.

Mitigation: Keep secrets server-side, avoid exposing secret values with public client prefixes, and sanitize or avoid untrusted HTML.
