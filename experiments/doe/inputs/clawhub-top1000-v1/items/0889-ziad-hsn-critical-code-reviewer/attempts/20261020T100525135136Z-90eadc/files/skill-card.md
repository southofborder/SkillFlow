## Description:

Conducts rigorous, adversarial code reviews that identify security issues, edge case failures, bad practices, and code quality problems across Python, R, JavaScript/TypeScript, SQL, and front-end code.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and engineering teams use this skill to get strict code review feedback on code snippets or pull requests, with findings grouped by severity and paired with actionable remediation guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may flag context-sensitive issues from partial code snippets where the surrounding codebase or team conventions are unavailable.

Mitigation: Verify findings against the full codebase and relevant conventions before acting, especially when the reviewed input is incomplete.
