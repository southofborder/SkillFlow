## Use Case:

Developers and learners use this skill to get code explanations that combine analogies, ASCII diagrams, step-by-step execution walkthroughs, and common-mistake callouts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may receive Chinese-oriented explanations when they expect another language.

Mitigation: Clarify or follow the user's preferred language before explaining code.

Risk: Analogies and diagrams can oversimplify code behavior.

Mitigation: Pair each analogy or diagram with a step-by-step walkthrough of the actual code behavior.
