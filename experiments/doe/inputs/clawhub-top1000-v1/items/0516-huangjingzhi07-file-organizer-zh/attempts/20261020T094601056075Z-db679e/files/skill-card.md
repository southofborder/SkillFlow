## Description:

A Chinese-language file organizer that classifies local files into type-based folders.

This skill is ready for commercial/non-commercial use.

## Publisher:

[huangjingzhi07](https://clawhub.ai/user/huangjingzhi07)

### License/Terms of Use:

MIT

## Use Case:

Developers and end users working in Chinese use this skill to inspect or reorganize folders such as Desktop, Downloads, Documents, or explicit Windows paths into file-type categories.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can move many local files automatically without a preview or confirmation.

Mitigation: Use it only on backed-up directories or folders that can be safely rearranged, and request statistics or view mode before organizing when possible.
