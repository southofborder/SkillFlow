## Description:

Executes and critiques visual design with quantified guidance for hierarchy, spacing, type scale, color, layout, accessibility, and common artifact formats.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ivangdavila](https://clawhub.ai/user/ivangdavila)

### License/Terms of Use:

MIT-0

## Use Case:

External users, designers, and developers use this skill to create or review UI screens, landing pages, slides, graphics, emails, charts, documents, and visual design decisions. It helps diagnose weak hierarchy, spacing, typography, color, layout, accessibility, and responsive behavior in practical design work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can reuse or update design preferences under ~/Clawic/data/design/.

Mitigation: Review or remove those files before installation or use if persistent design preferences should not be applied across sessions.
