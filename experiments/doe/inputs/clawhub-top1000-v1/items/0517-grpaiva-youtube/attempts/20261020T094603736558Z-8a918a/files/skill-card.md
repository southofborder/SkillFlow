## Description:

Search YouTube videos, get channel info, fetch video details and transcripts using YouTube Data API v3 via MCP server or yt-dlp fallback.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, researchers, and content analysts use this skill to search YouTube, retrieve video and channel metadata, and collect transcripts for review or downstream analysis.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Mutable third-party installs and global tooling can change behavior after release.

Mitigation: Review dependencies before use, prefer pinned versions, and run the MCP server or yt-dlp in an isolated environment when possible.

Risk: The YouTube API key is provided to local command-line tooling and could be exposed through an overly broad process environment.

Mitigation: Provide only YOUTUBE_API_KEY to the process that needs it, restrict the key to YouTube Data API v3, and apply quota controls in Google Cloud.

Risk: Transcript files generated by yt-dlp can persist in local temporary paths and may contain sensitive reviewed content.

Mitigation: Store transcript outputs in controlled locations and delete local files when they are no longer needed.

Risk: Auto-generated transcripts can be inaccurate or incomplete.

Mitigation: Verify transcript text against the source video before using it for quotes, claims, or decisions.
