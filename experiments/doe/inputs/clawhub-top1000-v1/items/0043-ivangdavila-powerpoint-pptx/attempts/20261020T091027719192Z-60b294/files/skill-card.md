## Description:

Create, inspect, and edit Microsoft PowerPoint presentations and PPTX decks with reliable handling of layouts, templates, placeholders, notes, charts, and visual QA.

This skill is ready for commercial/non-commercial use.

## Use Case:

Employees, external users, and developers use this skill when creating, inspecting, or editing PowerPoint decks where template fidelity, placeholders, notes, comments, charts, and rendered visual quality matter.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: PowerPoint review can expose confidential material in visible slides, speaker notes, comments, media, and linked assets.

Mitigation: Use the skill only with presentations the agent is authorized to inspect, and review notes, comments, media, and linked assets before sharing results.

Risk: Deck edits can leave broken layouts, placeholder text, clipped content, weak contrast, or stale chart and table semantics.

Mitigation: Run separate content and visual QA passes, render or inspect the actual deck output, and re-check affected slides after fixes.
