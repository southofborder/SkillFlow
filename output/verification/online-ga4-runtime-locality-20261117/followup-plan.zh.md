# 基于本轮结果的后续方案（尚未实施）

本轮唯一运行及唯一重放已关闭。以下是建议，不是下一轮启动授权；保持现有产物和失败记录，不重放历史运行或修改历史结论。

1. **先验证失败动作的反向保护，再缩小全局阻断。** 两次独立静态复核发现：必需 action 所在 IR 没有操作记录时，IR action seed 可被记为已绑定，但 op_key=None 不回传输入；失败诊断仅覆盖失败点与下游，已处理上游输入可能无需求且不受约束。这是有代码路径依据、尚未执行的条件性风险，不是已证实的线上误删。新增最小离线例：已处理 producer/acquisition 产生 x，必需 deliver(x) 前遇到已知域错误，独立 y 正常完成；x 应局部 unresolved 且不可删，y 不受无关扩大。覆盖成功前缀、其他成功路径、多个消费者、强覆盖写和 FIFO/LIFO。应保留带 requirement、动作与已知操作数关系的未完成义务，不虚构未执行的工具响应，也不把所有候选输入硬判 required。

2. **processing 一次聚合可确定诊断，并支持跨表的有限修订。** 本轮 modeled/unmodeled 在两条已知 IR 上重叠，却生成全局 /ir_semantics 诊断并触发全量替换；13 条源文机制引用错误也在同次纠错中。前层失败还遮住了已存在的 ir_001 资源身份误作载荷问题。应在独立记录可编译的范围内聚合引用角色、绑定和跨表诊断，仍拒绝有歧义结构，不猜测正确值。为已知 modeled/unmodeled 冲突建立明确记录闭包，锁住其他记录及证据，完整合并后严格校验。用本轮 19 个 reply→date-range 错绑写新离线回归：局部修订不得改动未受影响返回绑定；不要假定 a001 的其他内容全部正确。无需增加正常请求或纠错预算。

3. **补齐输出信息分解，随后局部化 Task 缺口。** 89 份整体 value 契约没有形成可用的细粒度基础，实际触发 22 条输出信息缺口，涉及字段、truth 和 shape。processing 应只按操作自身输出语义提供字段／信息属性分解；可确定构造继续用确定性规则，不能为了当前 Task 反向定制 processing。整体输出规则不能充当任意子字段规则。审查应明确检查 settings 各字段、分页参数、集合结构和真假需求的充分性／必要性与输出覆盖。另一方面，把 requirement_expression_gap、unbound_requirement 和 task_source_issue 绑定到具体 requirement、输出义务、动作、条件及可验证依赖范围；只有有明确跨范围影响依据时才保持全局。保留源文真实歧义，不把问题删掉以消除 partial。先完成第 1 项，否则收窄 70 条全局阻断可能暴露被其掩盖的删除风险。

4. **补齐 local guard 与容器版本的可证明关联。** ir_457/459 的 missing_part 来自成功／异常 wrapper 没有随 fulfilled 判别收窄；不是源文缺字段。对受支持的直接 select、明确版本和局部别名建立有证据的条件关联，成功边排除不匹配 wrapper，异常边仍保留异常。不能对不透明计算推造逆关系，也不能因字符串字段名相同收窄另一对象。离线覆盖 guard 未发布为 IR output、多个 wrapper 版本、local 覆盖、相同真假值、嵌套成员、真正未知 predicate 与独立状态。继续保留缺字段严格检查。

5. **分离传输原因与生成规模，调查约 15 分钟的重复失败。** 本轮已有 TLS EOF→WebSocket 重试→HTTP 回退→约 903／902 秒响应体解码错误→本地 2700 秒截止的证据链；尚无具体代理／服务端计时器证据。优先从可公开记录的连接建立、响应头、流活动和最终退出时间补齐观测，避免保存私有推理或凭证。没有完整图答复，不能给出其实际输出规模或纯生成耗时，也不能断言降低字符数即可治好网络失败。根据新证据再决定传输修复；不先增加超时、重试或采样预算，不用额外模型探针替代离线复现。

受支持操作规范应继续成为机器核对的有限契约，并补充组合不变量：引用角色、值与地址、判别字段关联、状态／成员／控制依赖、必需动作失败后的正向和反向影响。不能靠无限列举任意 Skill 场景保证语义正确。合法的有依据未决仍应保留，但范围必须可解释。

下一次验收首先应验证上述最小失败例、输出字段／truth／shape 分解与多用途取并集、局部 Task 缺口、原始观察保持、整槽与字段删除区别、严格审查身份和既有预算。保留每次原始失败及修正证据。若之后另行获准线上实验，应明确选定新运行与源材料，并单独报告生成变化、实际边界语义、所有输入范围、已知与未知成本，不能用 processed 数量代替正确性。
