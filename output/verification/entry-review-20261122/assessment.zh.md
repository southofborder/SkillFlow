# GA4 前的离线核验

通用修复已落在产品代码中。真实 Lean 证书回归在 Windows 创建子进程时收到 WinError 4551。Code Integrity 事件 3077 记录了拒绝执行的文件和签名策略。文件 SHA-256 与上轮封存的 GA4 图证书一致。即使复用同一 CFG，控制器也会在首个模型请求之前调用该程序解析和渲染证书。GitHub 同步和本轮 GA4 的顺序依赖这项验收。[系统事件和哈希](renderer-policy.json) · [失败用例](seven-stage-frozen.junit.xml)

五个目录的完整测试和补充用例按测试身份去重，共 4,979 项通过、3 项跳过、1 项失败。跳过项分别涉及 Windows 符号链接权限和两组可选本地历史材料。唯一失败项为上述真实证书回归。产品代码与形式化源文件摘要为 `1d45556ea5232befc0748581e90e445ed42d16ecd351672541112fb1a2f5ad50`。[离线结果和逐套件记录](offline-results.json)

| 核验对象 | 离线结果 |
| --- | --- |
| 修订权限 | 用上轮材料构造出的 31 个可编辑 IR 覆盖 ir_167、ir_311、ir_329、ir_346。四项都附原始校验诊断，拒绝 keep。91 项 location 声明可读。六个改写 IR 漏填的 23 项 demand_transfer 和 1 项工具接口契约可以在一次校验中全部定位。 |
| 分支 | 四处判断读取同一不可变输入时，三分支得到 3 种可行类别组合。四个独立输入得到 81 种。两种队列顺序的完整记录一致。只测对象种类时，无其他用途的子字段仍可删除。 |
| 敏感入口 | 同一数据和两个接收方的回归中，限定在一次读取上的标注只到达对应接收方。对上轮 100 条已到达的凭据声明做离线对照，假设证据支持字段本身敏感，可以形成两组，每组保留 50 条记录。改为访问限定时，保留 100 条独立声明。 |
| 字段删除 | 三输入用例中，任务只要求前两项的字段，第三项可删，原始读取、传播和观察记录均保留。 |
| 报告 | 在共享证据的受控样例中，5,000 个候选生成 2,835,225 字节 HTML 和 2,834,748 字节 Markdown。公布两个文件共用 3.61 秒，期间 Python 分配峰值 1,752,920 字节。新 GA4 的候选数量和文件大小仍待实测。 |
| 兼容性 | 已按原身份读取并校验上轮 DOE v12、demand v12、sensitivity v10，以及绑定的 425 项审查记录。此次只读核验未启动模型或重放。 |

同一份旧 CFG、processing 和完整 16 文件源文，在当前代码上的交付体积分别为局部 processing 修订 375,659 字符，敏感性 585,616 字符，Task 对应 516,752 字符。三者均包含实际 CLI 前缀，并通过 1,048,576 字符的提交前检查。敏感性清单新增了可解析的入口和访问坐标。[交付证据](saved-material.json) · [来源对照](ingress-identity-check.json) · [分支回归](branch-version-products.junit.xml) · [报告测量](report-publication.json)

本轮实验模型请求为零。可修权限和注入答复的修复结果已经离线验证。哪几个旧问题会在新 GA4 再次出现、能否得到已审查的修复、新一轮的真实来源数、字段删除位置与公开 token 用量，均须由新运行报告。
