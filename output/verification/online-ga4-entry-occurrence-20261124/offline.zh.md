# GA4 入口采集的离线验收

使用与上轮相同的 16 文件源文，校验原始模型答复，并在闭合的三入口样例上运行程序的实际编译、有限纠错和传播流程。测试中的语义纠错答复由夹具提供。

| 材料 | 检查 | 证据 |
|---|---|---|
| 上轮完整的 163 块 CFG 原答 | 唯一的 18 键接收触发 `acquisition_occurrence`。修订可修改入口、七个报告函数所在的选择分支和真正消费合并参数的操作。78 个块在可改范围内，模型可以只提交变化的块。 | [原答与修订范围](saved-answer-check.json) |
| 原始 processing 与真实入口摘录 | 18 个旧输出和旧位置绑定触发有限纠错，保留独立记录。测试将实际合并结果交付给传播器。 | [可复现夹具](../../../tests/fixtures/ga4_entry_occurrences/README.md) |
| 两个独立调用和一个共同调用方 | 分别追踪四次 SDK 查询的请求字段、配对响应第 0 项及保存版本。两次独立调用各用自己的参数，另外两次均使用 `siteOverview` 传入的同一版本；总览的两个字段分别绑定对应的响应。 | [传播断言](../../../tests/document_guided/test_ga4_entry_occurrence_trace.py) |
| 改变控制边及实参的反例 | 交换两条路线及其值后，图仍可达。正常构图和局部纠错都能定位调用来源矛盾。 | [调用归属回归](../../../tests/document_guided/test_graph_entry_occurrences.py) |
| 上轮修订中的实际合并点 | 新图 `ir_262` 的过滤结果由 `block_171` 产生，通过该前驱到达合并点。修订输入列出新边、输入值及其生产位置。 | [新图前驱](saved-answer-check.json) |

独立调用样例覆盖对象输入、参数省略、显式空值、空字符串、已提供但内容未知，以及是否提供也未知。两种遍历次序分别核对相同的已记录值和结果。源文件通过快照读入，所有查询与保存均由静态传播器建模。

仓库可移植回归使用原答摘录及固定源文。另可在保留了上轮运行的工作区执行 `python -B output/verification/online-ga4-entry-occurrence-20261124/check_prior.py`，核对夹具与完整原件的摘要、相关块、processing 记录以及新修订输入。全仓测试的计数、跳过原因与测试组摘要保存在[离线验收收据](offline-acceptance.json)。
